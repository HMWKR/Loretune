## 공통 에이전트 작업 공간·권한 계약 보충 · 2026-10-28

**최신 사용자 확정 요구이며 구현·검증 중이다.** 기존 대화별 이력·초안·선택 모델 격리와 공유 버전·예산·권리 계약을 유지한다. UI를 옮긴 사실이나 합성 응답을 실제 모델의 전체 플랫폼 이해로 표현하지 않는다. 현행 구현 증거와 잔여는 [작업 기록](../qa/codex-workflow-review-20261027/REPORT-ko.md)을 따른다.

|추적 ID|설계·구현 계약|필요한 검증|
|---|---|---|
|AGENT-UI-01|공통 우측 사이드 패널, 기본 AI 대화 열림, 상단 toggle·닫기/재열기·너비 조절. AI 대화/작업 설정 공간을 공유하며 대화 선택·모델·입력을 동일 DOM으로 재사용|음악/계획/장면/편집·출력·모션/3D 창에서 접근, 초안·포커스·모델·패널 너비 유지. modal의 외부 inert를 z-index로 우회하지 않고 같은 DOM을 허용된 host로 이동/복귀|
|AGENT-TOOLS-02|선택한 모델이 지원 typed 도구로 현재 음원·장면·저장 편집·결과를 검색하고 제안·편집·생성·안전한 설정을 지원|모델의 설명과 server diff/실제 저장·render 일치. 미저장 입력은 저장 문맥과 별도로 표시. 영상/사진 metadata 조회를 실제 픽셀 관찰로 표현하지 않음|
|AGENT-STATUS-03|작품별 실제 작업 진행·완료·실패 및 필요 시 실제 작업자 현황|작업 상태는 scoped 저장 상태/로그와 일치. 현재 실제 인증·팀 ACL/presence가 없으므로 사람 현황은 구현 후속이며 대화/엔진 worker를 협업자로 표시하지 않음|
|AGENT-REASON-04|모델별 실제 지원 추론 강도만 제시, 설정과 요청의 실효값/적용 시점 고정|서버 capability validation, 무효 값 거절, 전송 본문·재열기·모델 전환·진행 중 요청 불변. 모든 모델에 같은 옵션을 부여하거나 조용히 대체하지 않음|
|AGENT-PERM-05|permission/Full Access에도 계정 삭제는 항상 금지. 파일 등 다른 삭제는 대상·영향을 제시한 해당 삭제의 사용자 명시 허용이 필요|UI 표시가 아닌 서버 도구·대상·버전 검사. 포괄 권한/무응답을 삭제 허용으로 해석하지 않으며 오래된 허용·변경된 대상/버전·재시작 우회 차단|

Full Access는 작업 권한의 범위이며 비용 상한·외부 자료 전송 동의·권리·변경안/최종 출력 승인을 자동 무효화하지 않는다. 추천/초안 준비, 되돌릴 수 있는 편집, 실제 자산 삭제, 유료 생성의 범위를 typed allowlist와 실제 상태 전이로 구분한다. AI가 자신의 permission·비용·전송 범위를 몰래 넓힐 수 없어야 한다. 설정 변경도 현재 실행의 frozen model/본문/예산을 바꾸지 않고 명시된 적용 시점을 따른다.

[14개 과업 source 감사](../../.omo/evidence/first-demo-20261028/chat-capability-audit/report.json)는 조회·장면 계획·타임라인·타이포·로컬 출력의 일반 대화6개 도구와, 영상 생성/3D/설정/전체 작업 조회/실제 프레임·외부 자산 검색의 연결 공백을 구분했다. 감사 당시 일반 대화 선택은 Claude만 허용하며 GPT/xAI 카탈로그 등록은 같은 실행 지원을 뜻하지 않는다. 후속 typed 타이포 겹치기 명령의 schema 추가는 실제 UI·모델 수용과 별개다.

DEMO-01은 실제 UI 조작→API→입력/권리/비용/승인→작업→저장→재조회→미리보기→편집·출력·다운로드·재열기를 요청/작업 ID·버전·[요구 추적표](../../.omo/evidence/first-demo-20261028/requirements-trace.json)·녹화 타임코드로 연결한다. 1차 녹화 검토와 명시적 구체 승인 전 AI 영상 모델을 호출하지 않는다. Claude 실호출도 승인 모델·전송 자료·예산 범위를 따로 확인하고 합성 시험으로 대체 완료하지 않는다. 아래 CS01–18 및 과거 결정은 원문을 보존하며 이번 요청으로 조용히 제외하지 않는다.
