## 진행 중 · 공통 AI 작업 패널·1차 시연 · 2026-10-28

**음원 기반 음악영상 제작·편집·출력이 중심이며 전체 플랫폼은 미완성이다.** 음원만으로 시작하고 사진·3D는 선택한다. 최신 사용자 요청은 모든 제작 단계와 모션·3D 작업창에서 열 수 있는 오른쪽 AI 사이드 패널이다. 기본 열림·닫기/재열기·너비 조절, 대화별 모델·초안 유지, 모델별 추론 강도와 권한 설정을 구현·검증 중이다.

- **확정 권한 정책:** Full Access도 계정 삭제를 허용하지 않는다. 파일 등 다른 삭제는 대상·영향을 보여 주고 해당 삭제에 대한 사용자 명시 허용이 있어야 한다. 비용 상한·자료 전송 동의·권리·최종 출력 승인은 별도다.
- **현재 연결 공백:** [선택 모델·도구 감사](.omo/evidence/first-demo-20261028/chat-capability-audit/report.json)에서 일반 대화의 영상 생성·3D 편집·설정 변경·전체 작업 조회·영상 프레임 분석·외부 자산 검색 연결을 구분했다. 도구나 화면의 존재를 실제 AI 사용 완료로 표시하지 않는다. 실제 협업자·권한 데이터 없이 작업 ID를 작업자로 표시하지 않는다.
- **검증 시점:** S850의850개 통과 이후 첫 시연 준비 소스에서874개 중3건 실패를 보존했고, 정산된 취소의 구 기대값을 정합화한 뒤874개/492.666초 통과를 기록했다. 이 검사는 이후 정상 송신 안내·AI 도구·사이드 패널 변경 이전 결과다. [실행별 증거와 잔여](docs/qa/codex-workflow-review-20261027/REPORT-ko.md)를 따른다.
- **1차 시연은 아직 미완료:** 실제 UI 리허설의 음원 단독3초 출력·재생과 사진/영상 위 타이포 합성 프레임은 확보했다. 전달 가능한 연속 화면 녹화·타임코드·요구별 내부 실행 추적은 준비 중이다. 실제 AI 영상 모델은 녹화본 검토와 구체적 모델·자료·횟수·최대 비용 승인 이후에만 호출한다. 실제 Claude도 별도 승인·검증 대상이다.
