### F1 — 연출 취향 적용 범위에서 "이 IP" 선택지 소실 · **High** · P1

## Minor Observations

- 런타임에 `<h2>` 구역 제목이 disclosure의 summary로 바뀐다(`index.html:979-984`). 그 결과 인스펙터에서 제목 탐색(H 키)이 거의 불가능하다. summary 안에 `<h3>`를 두는 방식을 검토할 것.
- `h1`이 셋 이상이다(`#shotTitle` `index.html:22`, `#projectEmpty` `:21`, `#chatPanel` `:19`).
- `button:disabled { cursor:wait }`(`studio.css:75`)는 `.lt-ui` 규칙(`studio.css:286`, `:505`)이 덮지만, 기본 규칙에 의미가 다른 커서가 남아 있다.
- 비활성 글자색 `--ui-control` #858585 on #242424 = 4.21:1(`studio.css:505`). 비활성 요소는 WCAG 1.4.3 예외라 위반은 아니지만 `--ui-disabled`(6.36:1)가 따로 있는데 쓰이지 않는다 → 토큰 일관성.
- 작업 상태 1.5초 폴링(`chat-sidebar.js:298`)은 서명 비교로 불필요한 재렌더를 막는다(좋음).
