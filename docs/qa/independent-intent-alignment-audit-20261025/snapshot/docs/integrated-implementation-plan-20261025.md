## 순서와 완료 기준

1. P1-production (FR031–042,055–069): 같은 프로젝트의 빠른 제작/상세 작업대. 음악버전→샷계획→역할별참조/첫프레임→검토→선택take→저장타임라인→실제MP4. 첫 작업은 참조역할/승인과 변경영향 고정. 원본take·완료export를 바꾸지 않고 새 계획만 검토대기로 만든다. UI는 입력/준비/생성가능여부/비용/공개범위를 생성행동 근처에 명시. 완료는 입력·오류·재진입·영향·음원MP4의 서버/브라우저 검증으로 판단한다.
2. P2-memory-assets (FR007–030,070–078): IP·세계관/취향 버전,근거·정정·선택계승,역할별자산검색/비교,권리/삭제영향. 과거곡과승인본보존·다른IP범위·복원 시험 필요.
3. P3-provider-cost (FR043–054,079–084): 실제capability·견적유효성·예약/원장·중복/취소/미확정상태. 미연결은 blocked,로컬합성과AI생성분리. 모델선정은 경쟁사품질 우위로 정당화하지 않는다. 실제연결·유료실행은 승인점에 도달하기 전 호출하지 않는다.
4. P4-access-operations (나머지 FR): 인증/조직권한·명세API·관측·백업/삭제·접근성. 실제권한검사 없는 local-owner를 인증이라고 부르지 않는다. API는 OpenAPI 요청/응답/권한/충돌/오류 계약을 모두 확인해야 완료로 센다. 운영보안 설정은 변경하지 않는다.

동봉 JSON은 96FR 전부와 143operation 전부를 단계에 매핑한다. 기존 implementation-matrix/api-contract-coverage를 정본 진척표로 유지하며 라우트별 성공 응답만으로 계약완료를 선언하지 않는다.

## 승인 경계와 검증

로컬코드·격리시험·합성테스트미디어·로컬렌더는 승인범위다. 외부API자격증명 생성/설정,유료생성/결제,외부배포/push,시스템보안변경은 별도승인 필요. provider미연결은AI완료표시 금지. 외부계정/권한/무료·비공개조건이 불명확하면 호출하지 않는다.
