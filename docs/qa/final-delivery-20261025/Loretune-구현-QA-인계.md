# Loretune 로컬 MVP 구현·QA 인계

현재 결과는 **로컬 제작 흐름을 실제 파일·DB·렌더로 검증한 개발판**입니다. 채팅/미디어 공급자 계약과 화면을 연결했지만, 모든 모델의 실연동이나 유료 서비스 출시 완료를 의미하지 않습니다. 이번 전달 작업은 코드 변경·키 조회·유료 호출 없이 최종 화면과 기존 증거를 정리했습니다.

## 확정한 제품 구조

07 문서와 이후 사용자 확인을 기준으로, 채팅/기획 모델과 이미지·영상 모델을 독립 선택합니다. 선택된 채팅 모델이 서버의 정식 IP·온톨로지 문맥을 읽고 제작 도구를 요청하면, Loretune이 권한·사용권·입력 버전·견적·사람 승인을 검증하여 선택한 fal.ai 이미지/영상 API로 전달합니다. 모델이 직접 승인 권한을 갖거나 임의 API를 호출하지 않습니다.

MCP는 사용하지 않습니다. Runway·Higgsfield는 설명·벤치마킹 사례이며 활성 직접 연결 대상이 아닙니다. 모델 변경은 기존 프로젝트·자산·곡 한정 예외·진행 중 작업을 보존하고, 실패 시 다른 모델이나 모의 응답으로 몰래 대체하지 않습니다. 내부 ID·hash·grant·도구 추적은 진단/서버 기록에 두고 일반 제작 화면에는 모델, 비용, 승인 범위, 진행·실패·저장 상태를 보여줍니다.

## UI와 오류 처리 개선

음악 입력→계획 검토→장면 제작·검토→편집·출력의 같은 프로젝트 흐름을 제공하고 상세 제어는 펼침으로 배치했습니다. 미리보기·Take·타임라인을 가까이 두고 서로 다른 비율의 비교 미디어를 동일 높이 contain 영역에서 표시합니다. 선택, 검토 승인, 편집 사용, 최종 출력 승인은 별개입니다. 저장된 모델이 사용 불가여도 ‘미선택’으로 지우지 않습니다.

검토 초안은 작품·장면·Take별로 보존하며, 저장 대기 중 새 입력을 이전 응답이 지우지 않습니다. 명시적 저장 거절은 폼 옆에서 입력 보존과 실제 저장 버튼을 안내합니다. 응답 유실은 실패로 단정하지 않고 기존 요청 확인만 제공하며, 조회404도 unknown으로 유지해 재제출하지 않습니다. 저장 완료 확인 후 화면 조회만 실패하면 완료 사실을 유지합니다. 출처·사용권은 데스크톱/모바일에 같은 chevron, 열린 상태, 키보드 포커스를 제공합니다.

## 최종 QA 근거

- 전체 회귀 **327/327 통과, 42.909초**. 기능 완성도 비율로 환산하지 않았습니다.
- Python AST111개·inline JS4개 정적 검사 통과.
- 실제 브라우저에서 다중 장면/Take, 혼합 비율 비교, 승인과 선택 분리, 기존 결과 회수, 자막 포함 출력, 재시작 복원을 검증했습니다. 외부 채팅/미디어가 fixture인 구간은 각 보고서에 구분했습니다.
- 최종 저장 오류 시험은 통제된 브라우저 응답 대역입니다. 실제 서버 장애·저장 성공을 가장하지 않았고, 실제 변경 POST0·외부 모델 호출0입니다. 400/403, network/5xx/JSON 유실, unknown404, committed 후 갱신 실패와 최신 초안 보존을 회귀로 검증했습니다.
- 이번 최종 데스크톱/모바일/펼침 이미지 세 장은 모두 아래 최종 B에서 새로 촬영하고 저장 픽셀을 확인했습니다. `capture-manifest.json`에 각 시각·파일 해시를 기록했습니다. 과거 오류 캡처 A와 섞어 최종 B라고 표시하지 않습니다.
- 독립 시각 검토자가 고정된 표본 체크리스트에서 **90/100(약 ±3), 다섯 차원 각각18점**으로 평가했고 저장 오류·disclosure 잔여 기준을 통과로 판정했습니다. 이는 휴리스틱 표본 화면 평가이며 출시 준비·경쟁사 동등성·접근성 인증이 아닙니다. 잔여 기준의 근거는 변경 없는 거절/미확정/펼침 경로의 A(a29802f3…14a73a)와 committed 후 갱신 실패 경로의 최종B(a59b8c49…373c1b)입니다. 두 버전의 유일한 후속 변경 범위를 검토자가 확인했으며 이번 사용자용 기본 화면 세 장은 모두B에서 촬영했습니다. 200/400% 실제 확대, 스크린리더 전체 여정, 실제 고객 사용성, WCAG 전체 준수를 검증했다고 주장하지 않습니다.

## 비용과 남은 실제 연결 조건

이전 Anthropic 시험의 누적 **usage×가격 계산액은 $0.0077580**이며 인보이스 실청구는 미확인입니다. 승인된 합성 시험 누적 한도 $50는 목표 지출액이 아닙니다. 이번 전달에서 추가 사용0입니다.

기존 fal 시험은 생성 완료 후 CDN403, 후속 시험은 토큰 발급403이라는 서로 다른 단계의 차단이 남았습니다. 첫 요청 $0.70 실청구 확인과 후속 실청구 미확인을 구분하여 기존 기록을 보존했습니다. 만료/거절 URL 재시도, 공개 전환, 새 유료 생성은 하지 않았습니다.

다음 live 단계는 공급자 계정/키 사용 범위·선택 모델·가격·전송 자료·비공개 파일 접근/수명·예산을 확인한 별도 승인 후 진행해야 합니다. fal 이미지→영상 입력 접근 호환성도 실제로 검증해야 합니다. OpenAI/Grok 계정 연결과 세 채팅×두 이미지×두 영상의 12개 실제 조합은 미검증입니다. 사용 가능한 모델로 활성화하지 않았습니다.

현재 제한된 단일 사용자 로컬 제작 여정에서 알려진 필수 UI 연결 누락은 이번 통합 범위에서 닫았습니다. 다만 **인증된 공급자 실청구 조회의 자동 대사는 완성된 기능이 아닙니다**. 현재 코드가 기록한 견적·사용량·확인된 청구/unknown만 사용합니다. 이는 단순 권한 승인만으로 완성됐다고 할 수 없는 후속 통합 범위입니다. 실계정 조건에 따른 어댑터 추가 수정 가능성도 live 검증 전 배제할 수 없습니다. 따라서 ‘영상 API만 해결하면 모든 제품 요구가 끝난다’고 단정하지 않습니다.

전체96FR/143API와 확장28 MS-FR/38 MS-AT는 더 넓은 제품 추적 범위입니다. 등록이나 fixture 통과를 전부 완료로 세지 않습니다. 다중 사용자 인증/팀 운영·클라우드 배포·운영 부하·상용 출시 준비는 이번 로컬 전달 범위 밖입니다.
