# 2026-10-26 디자인 요구·방법론 추가 합의

이 문서는 사용자의 최신 지시에 대한 **날짜가 있는 추가 합의**다. 원본07 아키텍처를 수정하거나 과거 QA 결과를 새로 시험한 결과처럼 바꾸지 않는다. 초기 설계 문서와 checkpoint는 [history](history/initial-design-stage-20261026/)에 보존했다.

## 확정 요구

- 주 화면은1920×1080 **CSS content viewport**, 보조 회귀는1280×900이다. 모바일의 기존 계약은 유지하지만 추가 작업은 보류한다.
- 표준 배율의 데스크톱 핵심 작업은 페이지 전체 세로 스크롤 없이 수행하는 방향이다. 장면·미리보기/transport·시간축·검토/편집 주요 조작을 같은 작업 공간에 둔다. 긴 목록·상세는 해당 패널에서 접근한다.
- 글자 확대와 작은 창에서는 reflow/적절한 스크롤을 허용한다. overflow:hidden이나 작은 글자로 접근 불가능한 내용을 감추는 방식은 수용하지 않는다.
- 디자인 전반에 과업→근거→이유→구현→검증의 추적표를 둔다. 색상·타입·간격·아이콘뿐 아니라 채팅/모델 선택·승인·오류 복구·편집도 포함한다.
- 색은 현재 중성 미디어 중심을 유지하되 의미와 상태를 정리한다. 특정 HEX/px/색 비율을 산업 표준 정답처럼 말하지 않는다.
- 모델 독립 선택, chat→tools→fal image/video, noMCP, 권리·비용·승인·결과 미확정 복구 계약을 보존한다. Runway는 벤치마크다. 새 공급자/API 활성화는 디자인 범위가 아니다.
- source integration과 구현/릴리스 보고서는 기능 담당, 설계/참고/토큰/방법론/rubric 문서는 디자인 담당이 소유한다.

## 제안이며 아직 확정 수치가 아닌 것

preview350/400px의 예산 예시, rail240/inspector320 예시, 일부 타입24px·행간 방향, 향후 OKLCH 사용은 설계 가설이다. 실제 렌더·긴 한국어·시간축·focus가 더 잘 작동하는 배분을 선택한다. 구현팀이 다른 수치로 요구를 충족해도 유효하다. 경쟁사 내부 수치를 계측한 것이 아니다.

## 평가 변경

새7축100점은 workspace20 /정보15 /색상15 /타입·간격15 /미디어15 /상태·키보드10 /시스템10이다. 이는 전문가 판단이며 객관적 경쟁사 서열이 아니다. 과거5축90점과 환산하지 않는다. [v1](desktop1920/RUBRIC-v1-ko.md)+[v1.1](desktop1920/RUBRIC-v1.1-ADDENDUM-ko.md)의26개 하위항목과 필수gate를 사용한다. 미검증은null, 평가 coverage를 별도 표시한다. 새 무스크롤 요구가 추가돼 이전 구성 결과와도 단순 비교하지 않는다.

## 변경하지 않은 문서·데이터

원본07 사양, backend/source/runtime/DB, 구현/릴리스 보고서, 과거 QA screenshot·시험 결과·Library ID는 편집하지 않았다. 기존 저장 오류/disclosure/DM01–03 종료 결과를 다시 미해결로 만들지 않았다. 현재 설계 문서의 낡은 ‘미구현/연결 불가/모바일 우선’ 문구만 이력과 함께 정리했다.
