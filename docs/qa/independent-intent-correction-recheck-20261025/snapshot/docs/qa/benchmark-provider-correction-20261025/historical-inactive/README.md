# 비활성 역사 자료

이 디렉토리는 Runway 예시를 실제 공급자 후보로 잘못 확장했던 미활성 프로토타입을 보존한다. 사용자는 2026-10-25 Runway의 역할을 경쟁사·디자인 벤치마크로 정정했다.

이 파일들은 실행 대상, 자동 발견 대상, 활성 모델 catalog 또는 배포 가능한 공급자 연결이 아니다. 원본 앱의 `runway_provider.py`는 즉시 차단하는 stub이며 catalog·action·queue에서 Runway를 제외했다. 실제 Runway 계정 연결이나 유료 호출을 수행했다는 증거로 사용하지 않는다.

기존 구현·테스트 이력을 보존하려는 사본이다. 여기의 endpoint/가격/정책이 현행이라고 보장하지 않으며, 사용자의 별도 요구 없이 재활성화하지 않는다. 현재 결과는 상위 `REPORT-ko.md` 및 `integrated/fixed-release.json`을 따른다.
