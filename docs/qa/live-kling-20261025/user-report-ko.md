# Kling 10초 실검증 결과: 생성 완료, 비공개 다운로드 차단

사용자가 승인한 **Kling 2.6 Pro 무음10초 생성 요청1회**를 접수했고 약5분40초 뒤 제공자 결과가 준비됐다. 추가 생성·자동 재시도·충전·구매는 하지 않았다.

## 확인된 결과

- 모델: `fal-ai/kling-video/v2.6/pro/image-to-video`.
- 입력: 승인된 기하학 PNG와 영문프롬프트. 동결파일 해시 일치. 음원·자막은 전송하지 않았다.
- 비공개 default forbid와3600초 만료를 생성 요청에 포함했다. 이것은 계정 전체 설정 변경이 아니다.
- 인증 없는 결과URL 접근은 **HTTP403**.
- 공식 토큰교환은 성공했으나 **해당 토큰으로 결과 CDN 다운로드도 HTTP403**. 다운로드2회 후 오류를 명확히 분류했고 더 반복하지 않았다. 원본FAL_KEY는 CDN으로 보내지 않았다.
- 키·토큰·결과URL을 대화/로그/보고서에 출력하지 않았다. 새 키 생성·저장 없이 기존 키를 서버메모리에서만 사용했고 실검증 프로세스는 종료됐다.
- 요청ID: `01a171d6-bf9e-7e72-a8c8-4eb2c5f83b1d`. 로컬작업ID: `0de9b6ee-8a50-4aaf-a54f-ed8a5d4c193c`.

## 차단과 미검증

**정확한 차단:** `v3b.fal.media`의 기존 생성 결과를 단기 Bearer 토큰으로 GET하는 동작이403으로 거절됐다. 토큰의 계정/소유권 매핑 또는 제공자 ACL 처리 중 무엇이 원인인지는 현재 증거로 확정할 수 없다. 익명403만으로 비공개 기능 전체가 정상이라고 판정하지 않는다.

공개 fallback·ACL 완화·다른키 사용·새 생성은 하지 않았다. 앱은 `import_blocked`, 원장 예약은 `uncertain`으로 남겼다. 입력과 요청기록은 보존되어 있다. 권한 문제가 해결됐다는 새 근거 없이 다운로드를 반복하지 않는다. 요청한1시간 만료 때문에 결과가 먼저 만료될 수 있으나 이를 피하려고 만료설정을 변경하거나 재생성하지 않는다.

파일을 수신하지 못해 **실제 영상 길이/해상도/내용/무음 여부, 한국어 자막과 음악의 최종 합성은 미검증**이다. 기존 합성 리허설 MP4를 실제 Kling 결과로 대체 표기하지 않는다. 이번 최종 결과 MP4는 없다.

별도 UI차단: 기존 QA 브라우저 공간2가 삭제돼 실제 생성 화면 회귀를 실행하지 못했다. 사용자 공간0을 조작하거나 임의로 대체하지 않았다.

## 비용과 MVP 판정

실행 직전 공식 무음요율$0.07/초를 확인했다. **예상$0.70**, 승인 로컬한도$1. 실제 사용량/청구액/잔액은 미확인이며 성공·403을 무료 또는 환급으로 해석하지 않는다. 추가 결제는 수행하지 않았다.

**MVP 전체 완료 아님.** 실제 모델접수·결과준비까지 확인했지만 비공개 결과 수신과 최종 출력이 차단됐다. 원격 출시·다중사용자 인증 준비도 별도 범위다. 필요한 다음 단계는 fal측 해당 requestID의 파일소유권/토큰접근 권한 확인이며, 권한 완화나 추가 생성은 이번 승인으로 수행하지 않는다.
