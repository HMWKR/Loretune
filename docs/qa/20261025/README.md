## 발견 결함과 수정

1. **승인 우회**: 이전 `render` 작업은 take/타임라인 승인 없이 동기 MP4를 생성했다. 현재 명시적으로 거부하고 승인 검사가 있는 `render_job` 경로를 사용한다. 실제 HTTP400도 확인했다.
2. **음원 사용권 누락**: 타임라인 승인에서 영상 take 사용권만 검사했다. 현재 선택 음원의 사용권 미확인도 거부한다. 실패 후 승인 상태 불변 회귀를 추가했다.
3. **출력 완료 근거 부족**: FFmpeg 종료만으로 완료 처리했다. 현재 실제 길이/해상도/음원/자막 트랙을 확인하고 최종 경로로 원자적 이동한다. 미완료 job의 MP4/SRT/JSON 다운로드를 거부한다. 제작 기록에 선택 take·참고 버전·설정·실측값을 저장한다.

4. **JSON 파일 다운로드 실패**: 파일 바이트를 객체로 다시 JSON 직렬화해 연결이 종료됐다. 원시 바이트를 그대로 보내도록 수정하고 HTTP 회귀 및 실제 동일 URL200을 확인했다.
