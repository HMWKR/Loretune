# 결정적 승인 영수증 독립 재검증 기준

범위: RECEIPT-MANIFEST 고정 소스. 제품 수정·provider/API·listener·브라우저 실행 없음.

1. 현재 서버 projection, 과거 tool result, 모델 원문을 분리하고 원문을 보존한다.
2. 현재 stale/버전 변경과 과거 true 영수증이 동시에 있어도 과거 승인을 현재로 표현하지 않는다.
3. 타 프로젝트/장면과 모델이 삽입한 receipt는 현재 서버 상태에 영향을 주지 않는다.
4. 조회/표시는 승인, 실행, DB state를 변경하지 않는다. 기존 font/context 실행 gate를 보존한다.
5. 실제 6개 응답 replay와 소스/저장 화면을 구분한다. 모델 자유서술 오류가 고쳐졌다고 주장하지 않는다.
6. 선택한 기존 7 receipt tests와 최소 독립 Python/Node 반례만 실행한다. 전체 410은 재실행하지 않는다.

판정은 프로젝트 계약에 대한 한정 판정이며 일반 UI·접근성·모델 품질 평가가 아니다.
