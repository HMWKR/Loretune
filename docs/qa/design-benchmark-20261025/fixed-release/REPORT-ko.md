## Neural Frames 참조의 출처와 적용

참조는 Neural Frames 공식 도움말의 [The Four Stages of Autopilot](https://help.neuralframes.com/en/articles/12038142-handbook-the-four-stages-of-autopilot)에 포함된 실제 제품 화면 이미지입니다. [공식 Track 이미지](../structure/neural-official-track.png), [공식 Storyboard 이미지](../structure/neural-official-storyboard.png), [원본 출처·해시](../structure/neural-source.json)를 보존했습니다. 2026-10-25에 확보했고 이미지 파일명은 2026-04-09를 나타냅니다.

이는 **공식 튜토리얼 스크린샷**이며 현재 로그인된 편집기를 직접 관찰한 캡처가 아닙니다. 자연 픽셀 크기는 각각 3194×1494, 3210×1690이고 CSS viewport와 DPR은 알려져 있지 않습니다. 따라서 타사 글자 크기·간격·색상 토큰을 정확히 계측했다고 주장하거나 동일 viewport 성능 점수로 비교하지 않았습니다. 이번 검증에서는 경쟁사 계정에 접근하거나 조작하지 않았습니다.

| 관찰한 참조 패턴 | Loretune 적용 | 남은 차이 |
|---|---|---|
| 짧은 단계 안내와 한 작업 영역 중심 구성 | 프로젝트 설정을 접고 단계·다음 행동을 압축 | 상태 안내 한 줄이 여전히 반복적 |

Loretune은 온톨로지·계획 승인·Take 검토·출력 버전을 구분해야 하므로 타사의 브랜드나 색상을 복제하지 않았습니다. 기존 중립 표면과 흰색 주요 버튼을 유지하고, 탐색·미디어·검토의 역할을 분리했습니다. 관련 [토큰·컴포넌트 결정](../structure/TOKENS-AND-STATES.md), [구조 결정](../structure/DECISIONS.md)은 이전 설계 산출물입니다.

## 같은 5개 기준의 평가

## 확인한 동작과 미검증 항목

- 1280/390px에서 핵심 화면과 타임라인을 실제 확인했습니다. 390px 미리보기 탭에 키보드 포커스를 둔 뒤 오른쪽 화살표를 누르면 검토 탭이 선택되고 포커스와 패널이 함께 이동했습니다.
- 데스크톱 모델 설정 대화상자에서 채팅·이미지·영상 선택과 미연결 사유를 확인했습니다. Escape로 닫힌 뒤 `모델 설정` 버튼으로 포커스가 돌아왔습니다. 설정 저장·외부 호출은 하지 않았습니다.
- 장면→편집·출력 이동 시 타임라인 승인·렌더 대기열·MP4/SRT/제작 기록·렌더 결과 검토 조작이 DOM에 유지됨을 확인했습니다. 해당 변경·생성 버튼은 누르지 않았습니다.
- 이번 세션의 출력 재생 버튼 클릭은 viewport가 호출 사이 변경되어 숨겨진 요소로 판정되어 실행되지 않았습니다. 이를 제품 결함이나 출력 재생 성공으로 기록하지 않습니다. 출력 영상 검증은 구현 보고서의 별도 근거입니다.
- 실제 브라우저 200%/400% 확대는 미검증입니다. 390px viewport 에뮬레이션이나 `scale: 1`을 확대 검사로 간주하지 않았습니다. 스크린리더, 전체 키보드 제작 완주, 오류·만료·반복 클릭·입력 보존·reduced-motion 전체 행렬도 이번 고정 릴리스의 독립 재시험 범위 밖입니다. 접근성 준수를 주장하지 않습니다.

## 다음 개선 우선순위

1. **검토 패널 설명 압축**: 현재 상태·비용·다음 행동을 짧은 요약으로 묶고, 영수증과 긴 기술 설명은 펼쳐 보기로 이동. 완료된 승인 상태에서 반복 실행·기록 버튼의 의미를 더 명료하게 표시.
2. **주요 행동과 보조 행동 위계**: 단계당 주요 CTA를 명확히 하고 기본 select/input/button의 크기·라벨·간격·상태 표현을 일관되게 다듬기. 완료·차단·미연결·진행 상태를 문장 길이에 의존하지 않도록 설계.
3. **모바일 상단과 편집 접근 개선**: 현재 작업 맥락을 유지하면서 중복 상태 문구를 축소하고, 정밀 편집의 음원·자막·버전 진입점을 더 쉽게 찾도록 구성.
4. **실제 과업으로 검증**: 권한 있는 비민감 실제 미디어와 다중 장면·긴 한국어 텍스트로 사용성 시험, 실제 확대와 스크린리더 검사. 실험 전에는 클릭 수·시간·경쟁력 향상을 수치로 주장하지 않기.
