# Neural Frames 삭제 영향·복구 방법: 승인된 읽기 전용 확인

## 결과 먼저

1. **기존 합성 WAV 원본은 로컬에 남아 있다.** 과거 manifest와 현재 SHA-256이 일치한다. 파일 변경·재업로드는 하지 않았다.
2. Neural Frames `/songs`에서는 해당 음원이 보이지 않는다. 이 상태는 삭제 직후와 승인 후 재조회에서 일치한다.
3. `/videos`의 All 목록은 **삭제 전에도, 삭제 후에도 빈 상태**였다. 따라서 이번 삭제로 연결 프로젝트/스토리보드/출력이 지워졌다고 단정할 근거가 없다. 반대로 그러한 객체가 별도로 남아 있다고 확인한 것도 아니다.
4. 현재 확인한 UI와 공식 도움말에서 수동 삭제 음원용 휴지통·복원·보존기간을 확인하지 못했다. **복구 가능 여부는 미확인**이다. 자동으로 복원하거나 새 업로드를 복원으로 간주하지 않는다.
5. 다음 확인 경로는 공식 지원팀에 삭제 범위와 원래 항목의 복원 가능성을 묻는 것이다. 문의 발송도 아직 하지 않았고 별도 승인이 필요하다.

## 승인과 조사 경계

사용자는 부모가 제시한 “데이터를 더 변경하지 않는 삭제 영향·복구 방법 읽기 전용 확인”에 진행을 승인했다. 이 확인에서는 기존 정상 Aside 세션의 현재 snapshot, 명확한 `Your Video Library` 탐색 링크, 명확한 `Filter list` 표시 메뉴만 읽었다. 새 로그인·복원·삭제·업로드·생성·계정 변경·메일/지원 문의 발송은 없다. 디자인 벤치마크를 재개하지 않았다.

## 현재 실제로 관측한 것

|대상|승인 후 읽기 관측|판정 한계|
|---|---|---|
|Music `/songs`|업로드 안내와 템플릿 곡3개. 기존 approved 음원 카드 없음|이름 변경·휴지통 이동·실제 객체 삭제 등 내부 저장 상태는 미확인|
|Video Library `/videos`|로딩 종료 후 All/Autopilot/Shortform, “Create your first video” 빈 상태|삭제 전 동일하게 비어 있었음. 삭제로 프로젝트까지 없어졌다는 인과관계 없음|
|Filter list|All / Exported / Unfinished만 표시|이 메뉴에는 Trash/Deleted/Restore 없음. 제품 전체에 복구 기능이 전혀 없다고 단정하지 않음|
|Storyboard·Clip·Output|개별 객체나 URL을 확보하지 못함|과거 자동 메일은 존재·연결·완성 출력의 직접 증거가 아님|
|계정/권한|기존 세션으로 정상 읽기 가능|계정 설정이나 자격증명은 조사하지 않음|

마지막 화면은 `/videos`의 Filter list 메뉴를 읽은 상태이며 이후 더 조작하지 않았다. 계정정보가 포함된 screenshot은 저장하거나 공유하지 않았다.

과거 승인 테스트 보고서가 기록한 파일명과 과거 Aside 작업 디렉터리의 해당 파일을 확인했다. 숨겨진 세션 로그나 비밀 파일은 읽지 않았으며, 알려진 테스트 입력 파일의 존재·크기·해시와 그 입력 manifest의 해당 항목만 확인했다.

- 크기: **882,044 bytes**

이는 기존 승인 합성 원본이 보존됐다는 근거다. 삭제된 공급자 객체의 해시는 확보하지 않았으므로 원격 바이트와의 직접 해시 대조는 아니다. 원격 UI의0:11 표기와 로컬 기록10초의 차이도 그대로 남긴다. 새로 만든 Loretune3초440Hz QA 파일은 이 원본과 다르다.

## 공식 문서에서 확인한 범위

- [Autopilot 네 단계 공식 안내](https://help.neuralframes.com/en/articles/12038142-handbook-the-four-stages-of-autopilot): Track의 Clips 영역이 해당 업로드 곡의 이전 비디오와 Storyboard로 연결된다고 설명한다. 곡 삭제 시 연결 객체가 어떻게 처리되는지, 수동 삭제 복구/휴지통은 설명하지 않는다.
- [공식 FAQ](https://help.neuralframes.com/en/articles/8876551-common-questions-and-answers):90일 비활성 시 비디오 자동 삭제를 언급한다. **수동 음원 삭제의 복구 기간이나 복구 보장으로 적용할 수 없다.**
- [기존 공식 FAQ 페이지](https://www.neuralframes.com/FAQ.html):브라우저/컴퓨터 중단 후 자동 저장 작업 재개를 설명한다. 이것도 사용자가 삭제한 음원의 undelete 설명은 아니다.
- [공식 지원 안내](https://help.neuralframes.com/en/articles/9138816-how-do-i-contact-support):Help Center 메시지, 이메일, Discord 지원 경로가 있다. 문의 시 문제 설명·계정 식별·브라우저·관련 URL 등의 정보를 요청한다. 지원팀이 이번 항목을 복구할 수 있다고 확인한 것은 아니다.

공식 도메인의 restore/deleted song/trash 검색에서는 해당 복구 문서를 찾지 못했다. 다른 음악 서비스의30일 휴지통 규칙은 Neural Frames에 적용하지 않았다. 유료 복구 비용이나 지원 응답 시간도 확인되지 않았다.
