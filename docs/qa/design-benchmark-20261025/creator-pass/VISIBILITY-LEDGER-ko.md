# 창작자 화면의 정보 분류·표시 결정

기준: 고정 0a8ef843…c6ae. E=결정 필수, C=선택적 문맥, D=운영·개발 진단, N=중복 안내. 이 표는 현재 주요 화면의 필드군을 묶은 감사다. 데이터·로그·검증 조건은 삭제하지 않는다. 유용한 정밀 편집도 숨겨 없애지 않는다.

고정 fixture에는 저장된 모델 대화·계획·image-recovery 카드가 없다. 그 빈 상태/정적 코드와 조건은 확인했지만 새 실제 공급자 작업을 실행해 populated 성공/실패를 증명한 것은 아니다. 합성 미디어·선택된 승인 Take·기존 출력은 실제 저장 fixture, 거절/미검토 선택/오류 상태 증거는 별도로 라벨링한 브라우저 투영이다.
