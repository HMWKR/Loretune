# 이번 범위의 유한한 수용 기준

기존5항목×20을 유지한다. 직전 실제본70(독립 평가71)에서 점수를 미리 올리지 않는다.18점씩은90의 예일 뿐 할당 점수가 아니다. 아래는 이번 세 패키지의 완료 조건이며, 통과했다고 자동90이 되지 않는다. 통합 pixels를 동일 rubric으로 독립 평가해야 한다. 새 editor 기능·리브랜딩은 이 범위 밖이다.

고정 packet: populated desktop, mixed-aspect comparison, mobile approved, mobile rejected/unreviewed, mobile dirty, simulated save error. image/video와production-state는보조근거. 같은QA프로젝트/viewport를사용한다.

통합후 남은 작업은 이 packet의 실제재캡처·행동회귀와 독립동일rubric검토다. 원격 모델 활성화, 새로운편집기능, 고객사용자시험을 이 패스 완료의 선행조건으로 추가하지 않는다. 실제200/400%zoom·screenreader·고객사용성은 별도미검증을계속표기한다.
