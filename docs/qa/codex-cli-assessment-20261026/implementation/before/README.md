## 실제 지원 흐름

1. IP 설정을 승인하고 시대/이야기 순서로 작품 생성. 기존 작품의 설정 스냅샷 보존.
2. 샷 추가 → 이미지/영상(16MB 이하) 연결. 수정 이유와 사용권 근거를 기록. 사용권은 사용자 진술이며 법적 검증이 아님.
3. 여러 take를 비교해 선택. **선택과 검토 승인 별도**: 선택 take의 승인/수정 요청/거절 및 이유를 기록.
4. 음원(WAV/MP3/M4A/FLAC/OGG)을 새 원본 버전으로 연결. 길이/샘플레이트/채널/codec을 실제 probe. 원본 불변.
5. “현재 take 선택 가져오기”로 샷 시퀀스 초안. 컷 순서 ↑↓, 길이, 소스 시작 위치, 음원 버전/시작 위치, 출력 프로필, 수동 자막 시작/끝/내용 편집.
6. 편집을 새 타임라인 버전으로 저장. 이전 버전 복원은 새 버전을 만들고 재승인 필요. 원본 take/오디오는 변경하지 않음.
7. 검토 의견을 타임코드로 기록·해결. 모든 참조 take 승인과 사용권, 미해결 의견을 확인한 후 타임라인 승인.
8. 렌더 대기열에 추가. SQLite에 고정된 입력 snapshot으로 background worker 실행. 다른 편집 가능. 대기/진행/완료/실패/취소/중단을 개별 ID로 표시.
9. MP4/SRT/제작 JSON 다운로드. 이후 선택/타임라인 변경 시 이전 결과 라벨. 변경된 결과 파일 해시는 다운로드 차단.
10. 자산함에서 검색/이미지·영상 필터/현재·전체 작품 범위 선택. 선택 샷에 정확한 출처 take를 새 take로 연결. 사용권과 계보만 복사하고 승인·선택은 상속하지 않음. 원본 프로젝트 불변.

## 렌더 범위와 한계

미리보기 640×360, 가로 1920×1080, 세로 1080×1920, 24fps. 최대30컷·600초. 클립 오디오는 제거하고 선택 원곡만 48kHz AAC로 결합. 원곡이 짧으면 무음으로 채움. 영상 짧은 부분은 마지막 프레임 유지. 프레임 양자화가 발생할 수 있으며 정량 동기화 목표 검증은 미완료.

자막은 MP4 **선택 가능한 mov_text 트랙**과 SRT. 번인·글꼴/위치/안전영역·파형·비트 분석·자동 전사·전환·효과·드래그/분할은 미지원. 브라우저 자체 플레이어의 자막 표시 호환성은 제한적일 수 있음. 독립 플레이어에서 자막 트랙 선택 가능.

이전 /api/action render 경로는 초기 로컬 초안 테스트 호환용이다. UI 최종 출력은 render_job만 사용하며 take/타임라인 승인을 확인한다. JSON 명세는 영상이 아니며 기존 Studio mock 견적은 실제 렌더 운영비가 아니다. 모델 미연결, 외부 호출비0, 로컬 연산 비용 미계측. API capabilities에 실제 지원/미지원 표시.

## 저장·복구·동시성

`data/studio.sqlite3` state/requests/jobs/audit, `data/assets` 원본 해시 파일, `data/exports` 결과 및 parts-ID 중간 클립. backup은 서버 종료 후 data 전체 복사. 전역 revision과 SQLite 트랜잭션으로 stale 변경409. 동일 request_id/내용 재전송은 기존 결과, 같은 ID 다른 내용은 충돌. UI 요청 중 중복 클릭 방지. 필드별 자동저장/다중 사용자 협업은 없음.

서버 재시작 시 running job은 interrupted로 기록하고 자동 재제출하지 않음. queued는 이어 실행. 취소는 FFmpeg 자식 프로세스를 중단하고 이미 완료된 중간 클립을 보존. 아직 UI에서 부분 클립을 직접 선택·재개하지 못함. 실패 재시도는 수정 후 새 명시적 렌더 요청이며 이전 결과 보존. 업로드 중단 복구/취소와 대용량 스트리밍은 미지원.

단일 로컬 작업실. local-owner는 인증된 계정이 아니며 조직/테넌트/다중 IP 권한 기능을 대신하지 않음. 프로젝트 간 자산함은 이 로컬 작업실 전체 범위다. 이름 중복 불가. 문서 명세의 전체 기능/143 API/51 테이블을 구현했다고 주장하지 않음.

## 수동 음악 구조와 설정 정정

음악 구간(원곡 절대 초)과 인트로/후렴 등의 구조를 사용자 수동 확정 버전으로 저장한다. 자동 비트/BPM/가사 분석은 하지 않는다. 채팅 초안은 현재 음악 버전을 고정하고 장면의 계획 길이를 배분한다. 저장된 타임라인은 자동 이동하지 않으므로 음원 시작과 컷 길이를 검토해야 한다.

설정 후보는 근거·이유·시대·적용 순서·정정할 버전과 함께 저장한다. 승인/거절은 별도이며 승인된 정정은 이후 작품에 적용한다. 이전 작품 스냅샷은 보존하고 동시 정정 충돌을 차단한다. local-owner는 조직 인증/역할을 대신하지 않는다.

## 백업·새 경로 복원

## 후속 로컬 기능

로컬 IP 생성과 IP별 승인 설정 스냅샷을 지원하며 조직 인증/권한과는 다르다. 자산함은 현재 IP와 승인 take 필터를 지원한다. 자산 사용 중지/재개는 동일 해시의 재사용·렌더·job 결과 다운로드에 전파되며 파일은 보존한다. 기존 legacy 초안 출력의 과거 참조는 소급 등록하지 않는다.

새 음원은 실제 PCM 간이 파형(최대 첫600초)과 낮은 음량 여부를 기록한다. BPM/구조/전사 추론은 아니다. 출력 전 저장된 편집의 승인·미해결 의견·음원 길이 경고를 표시한다.

응답 미확정 요청은 브라우저 IndexedDB에 입력을 보관하고 같은 ID로 상태 조회·재시도한다. 대용량 업로드도 브라우저 저장소 공간이 필요하다. 저장 성공 확인 후 복구 입력을 삭제한다. 전송 전 단절과 저장 후 응답유실을 실제 UI에서 검증했다.
