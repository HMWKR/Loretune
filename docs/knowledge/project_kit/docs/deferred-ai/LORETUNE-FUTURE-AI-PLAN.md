## 목표와 경계

사업화 이후 실제 이용과 데이터가 축적되면 Loretune 제작 흐름에 맞는 채팅·추천·영상 AI를 검토한다. 공개 기반 모델을 활용하는 방안이며 GPT·Claude급 모델을 처음부터 만드는 계획이 아니다. 데이터 수집, 학습, 유료 클라우드 연결, 제품 출시나 배포는 아직 승인되거나 실행되지 않았다.

## 후보 기능

1. 채팅: 음악·가사·사용자 요청을 토대로 장면 구성, 카메라 구도 및 영상 생성 프롬프트 제안.
2. 개인화: 선택·거절·수정 이력에서 사용자의 색감, 구도와 컷 선호를 추정. 우선 프로젝트 맥락과 추천으로 실험하고 모델 학습은 필요성이 증명된 후 검토.
3. 영상: 공개 영상 모델에 권리 확보된 예시를 이용해 스타일·움직임·인물 표현을 LoRA 등으로 추가 학습하는 실험. 긴 영상의 인물 일관성이나 음악 동기화는 별도의 참조·편집·평가가 필요하다.
4. 영상 선택: 생성 후보와 요청의 적합성을 평가해 사용자 검토를 돕는 방법을 비교.

## 후보 구조와 작업 흐름

```text
사용자 요청 / 선택 / 수정 / 평가
  → 서비스 데이터 저장 및 이용 범위 확인
  → 데이터 정리·권한 검토·학습용 데이터셋 버전 고정
  → 기준 모델 결과 측정 → 추가 학습 → 동일 조건 평가
  → 승인된 모델 버전만 배포 후보로 검토

영상 요청 → 작업 ID → 비동기 GPU 작업 → 결과 저장 → 사용자 확인
```

- 사용자별 선호는 개인화 저장소 또는 검색으로 시작할 수 있다. 다수 사용자 데이터로 공통 모델을 학습하는 일과 분리한다.
- Databricks는 데이터 정리, 정기 작업, 학습 및 평가 오케스트레이션 후보이다. Lakeflow Jobs와 GPU 컴퓨팅의 실제 지역·런타임·모델 호환성을 확인한다. Unity Catalog는 접근 제어와 데이터 계보 관리 후보이다.
- 영상 생성은 오래 걸릴 수 있어 별도 GPU 작업자나 외부 API와 Databricks 작업을 비교한다. 재시도·중복 실행 방지·취소·실패 표시·결과 저장·비용 한도를 설계한다.
- 영상 파일, 채팅, 프로젝트 정보와 선택 이력은 용도별로 구분한다. 최소 수집, 권한, 보관·삭제·학습 제외 요청, 데이터셋과 모델 계보를 법률·계약에 맞춰 결정한다. 가명처리만으로 익명이나 동의가 보장되는 것은 아니다.
- 외부 AI 결과물을 학습에 쓸 때는 해당 서비스의 계약 및 학습 제한을 검토한다. 공개 모델의 가중치·도구·학습 자료도 각각 사용 및 상업적 권리를 확인한다.

## 단계별 재검토 순서

1. **착수 판단:** 사업화 상태, 실제 사용자 수요, 비용 한도, 권리·데이터 가용성 확인. 재검토 시점을 1년으로 확정하지 않는다.
2. **기준 측정:** 같은 입력으로 기존 채팅·영상 모델 결과와 품질·시간·비용을 비교한다. 사람의 평가 기준과 별도 평가 데이터를 정한다.
3. **개인화 시제품:** 최소한의 허용된 이력으로 추천 또는 맥락 주입을 구현하고 효과를 측정한다. 충분한 비교 없이는 학습을 전제하지 않는다.
4. **채팅 모델 실험:** 품질 검토된 요청·응답 쌍으로 소형 공개 모델의 LoRA 등을 시험하고 기준 모델과 비교한다.
5. **영상 실험:** 공개 모델과 짧은 권리 확보 영상으로 생성 및 LoRA 가능성을 시험한다. 학습 전후의 품질, 일관성, 소요 시간과 비용을 기록한다.
6. **파이프라인 실험:** Databricks 및 대안에서 샘플 데이터 처리·GPU 학습·비동기 생성의 호환성, 재시도, 비용을 검증한다.
7. **운영 판단:** 이용자별 격리, 품질·지연·비용, 실패 대응 및 이전 모델로 되돌리는 방법을 검토하고 별도 결정한다.

## 실험 환경 및 한계

대화에서 제시한 개인 PC는 i5-14400F, RAM 64GB, RTX 5060 Ti VRAM 16GB다. 소형 채팅 모델, 사용자 데이터 분석, 짧은 영상 생성과 일부 소규모 학습 실험의 후보이다. 16GB VRAM으로 모든 영상 모델의 학습이나 큰 모델의 원활한 운영이 보장되지는 않는다. Wan 2.1 1.3B의 공개된 실행 메모리 수치는 학습 메모리 요구량이 아니다. 실제 OS·드라이버·모델·속도·비용은 미확인이다. ComfyUI는 모델을 연결해 실행하는 도구이며 모델 학습을 자동 보장하지 않는다.

## Codex 활용

사용자 지시에 따라 모델·라이선스·하드웨어 후보를 조사하고, 데이터 구조와 작업 흐름을 설계하며 실험 코드·평가 도구를 작성할 수 있다. 학습 전후 결과를 비교하고 로그·비용·실패를 분석한다. 사용자 PC나 클라우드에서 실제 실행하려면 접근 권한과 실행 환경이 필요하며, 품질 판단과 외부 데이터 사용·유료 실행·배포는 그때의 사용자 지시 및 승인 범위에 따른다.
