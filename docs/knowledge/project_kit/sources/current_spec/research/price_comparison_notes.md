# 공개 제작 견적 비교 노트 — 길이·범위·수정 조건

조사 기준일: **2026-10-23**. 자료는 제작사 또는 판매자 본인의 공개 상품 설명이다. 실제 견적 요청, 구매, 제작 의뢰, 샘플 품질 평가는 하지 않았다. 공개 가격 11건, 관련 플랫폼 정책 4건, 비교 제외·조건부 후보 5건을 `duration_pricing_sources.json`에 기록했다. 게시·수정일이 없는 페이지는 날짜를 추정하지 않았다.

## 1. 의사결정에 필요한 결론

**기존 외주가 항상 고가라는 전제는 성립하지 않는다.** 제공받은 음원·일러스트에 가사와 간단한 효과를 붙이는 저가 상품이 존재한다. 월 구독료를 받는 신규 플랫폼은 저빈도 사용 고객에게 비용상 불리할 수 있다. 비싼 제작 사례만 선택해 절감률을 제시하면 안 된다.

비교 단위는 영상 길이뿐 아니라 **누가 자산을 만들고, 누가 기획·편집·검수하며, 수정이 무엇을 포함하는가**이다. 기존 자산 편집, 새 일러스트 제작 포함, AI 생성 대행, 실제 촬영은 별도 범주로 제시한다. 공개 견적의 존재는 우리 플랫폼의 품질·가격 우위 또는 해당 공급자의 실제 납품 품질을 입증하지 않는다.

아래 금액은 환율로 변환하거나 초당 단가로 환산하지 않았다. ‘약’, ‘이내’, ‘시작가’, ‘세별’은 원문의 조건이므로 삭제하면 안 된다. 세금과 구매 수수료가 불명확한 경우 ‘포함’ 또는 ‘없음’으로 채우지 않는다.

## 4. 우리 플랫폼과 비교할 때의 조건

원본 음악과 신규 일러스트 제작이 양쪽 모두 제외되는 조건을 확인할 수 있는 우선 후보는 **DP-02·DP-06·DP-10**이다. DP-04도 자산 범위는 맞지만 수정 조건에 모순이 있다. DP-11은 자산 범위는 맞아도 입력 길이 기준이므로 출력 길이별 비용 표에 바로 넣을 수 없다. 범위가 맞아도 연출 밀도·해상도·실제 품질이 동등하다는 증거는 없다.

우리 측의 `월 249,000원 ÷ 월 제작 편수 N + 사용량`은 아직 검증하지 않은 가격 가설이다. N=1·4·8은 고객의 실제 사용량을 관측한 값이 아닌 민감도 시나리오로 표시한다. 비교에는 IP 온보딩, 기획·검수 노동, 생성 실패와 재시도, 승인 후 변경, 지원 인건비를 함께 고려해야 한다. 외주는 제작자의 노동이 가격에 포함되는 반면 플랫폼 사용자는 자신의 노동을 추가로 부담할 수 있다.

‘수정 2회’, ‘생성 후보 3개’, ‘승인 클릭 3번’은 서로 다른 단위다. 한 수정 회차는 여러 장면 요청을 묶을 수 있고, 한 생성 후보는 짧은 샷 하나일 수 있다. 작업 단위가 정의되기 전에는 ‘더 적은 횟수로 완성’ 같은 비교를 하지 않는다.

공개 견적만으로 고객의 총비용, 실제 수요, 시장 평균, 우리 절감률을 확정하지 않는다. 우리 사용량·인건비·환불·마진 계산은 별도 가설 모델과 실제 파일럿 데이터로 검증한다.

## 5. 세금·수수료와 상충 정보 처리

- 크몽 DP-01·DP-09: 상품 표시가와 구매 수수료 4.5%를 분리한다. 수수료에 VAT가 포함된다는 문구를 상품가 자체의 VAT 포함 증거로 전용하지 않는다.
- 코코나라 DP-P01·DP-P02: 판매자의 과세 상태와 세별 표시에 따라 소비세가 달라진다. 구매자 수수료는 5.5%이며 해당되는 경우 소비세를 더한 상품 금액에 적용한다. 모든 상품에 같은 세금 상태를 일괄 적용하지 않는다.
- 랜서스 DP-P04: 세금 포함 계약 금액에 구매자 수수료 5.5%가 추가된다. 판매자 수수료를 구매자 총액에 다시 더하지 않는다.
- 취소는 공급자별 문구와 플랫폼의 공통 절차를 함께 확인한다. ‘무료 수정’에서 무조건적인 취소·환불 보장을 추론하지 않는다.
- DP-02 검색 요약의 과거 가격과 현재 원문 가격이 달랐다. 이번 기록은 현재 본문을 채택했다. DP-X01의 90초 옵션은 본문의 최대 60초 안내와 충돌하여 대표 비교에서 제외했다.

## 6. PPT에 사용할 수 있는 주장과 피할 주장

**사용 가능한 핵심 문장:** “영상 길이를 명시한 공개 견적도 자산 제작·촬영·수정 범위가 달라 별도로 비교해야 한다.” “저가 리릭 편집 대안이 존재하므로 구독형 플랫폼의 경제성은 반복 제작량과 검수 노동을 함께 검증해야 한다.” “우리의 차별성은 단발 편집 가격 우위가 아니라, 반복 제작에서 IP 정보와 승인 이력을 재사용하는 효과를 실측하는 데 달려 있다.” 마지막 문장은 사업 가설이며 시장에서 입증된 사실이 아니다.

**사용하지 않을 문장:** “기존 MV 평균은 200만~400만원이다.” “3분 MV를 항상 몇 만원에 같은 품질로 만든다.” “외주보다 80% 절감한다.” “수정 세 번이면 전체 MV가 완성된다.” “공개 상품의 최저 가격으로 언제든 주문할 수 있다.”

주요 비교 슬라이드에는 DP-03과 DP-10 같은 저가 대안도 남긴다. 가격 옆에 길이, 자산 제공 조건, 수정 범위를 함께 적고, 세부 세금·옵션은 각주와 근거 표에 연결한다. 인용자는 아래 URL을 직접 열어 확인하고, 자료명·조회일을 표시한다.
