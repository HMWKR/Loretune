# 발표 작성용 기준 문장 v2

이 문서는 실제 PPT가 아니라 이후 PPT에 연결할 문장과 근거 묶음이다.
1. 목표 고객은 반복 제작을 하는 소형 IP 팀이다. 유료 수요는 아직 검증하지 않았다.
2. 준비된 IP의 후속 프로젝트는 초안 실행 전 네 가지 주요 결정을 목표로 한다. 전체 네 클릭 완성을 뜻하지 않는다.
3. 기존 제작의 12개 정규화 업무와 네 가지 결정 묶음은 다른 단위다. 둘로 67% 절감률을 계산하지 않는다.
4. 60초 혼합형의 편당 고객 현금은 70,913원, 180초 혼합형은 87,512원이라는 예산 시나리오다.
5. 두 수치는 월 249,000원 구독을 월 4편에 배부하고 외부 변동비의 1.30배를 더한 세전 가격 가설이다.
6. 180초 혼합형은 공급자 등 외부 변동비 19,432원, 고객 노동 37,500원 포함 경제 비용 125,012원으로 계산한다.
7. 180초는 품질이나 제품 지원을 확인한 결과가 아니다. 출시 약속·평균 제작비·고정 견적으로 쓰지 않는다.
8. 기존 저가 편집 상품도 존재한다. 동일 품질 최저가·세계 최초 기억형 영상 플랫폼을 주장하지 않는다.
9. 차별화 가설은 승인 설정·취향·수정 이력을 재사용해 다음 작품의 설명과 수정 부담을 줄이는 것이다.
10. 증명은 같은 모델·자료·예산의 대조 실험과 실제 유료 재사용으로 한다. 아직 실험은 not_run이다.
