# 1MV 개별 경쟁사 관찰 보고서

- 관찰 기준일: 2026-10-25
- 분석 유형: 기존 일반 브라우저 관찰 기록의 재정리
- REA 제품분석 Evidence: 이 사이트에는 없음
- 생성 결과: 0건, 품질: 미검증/미완료

## 1. 최종 결론·관찰/미확인 범위

- 1MV는 음악 영상 생성의 공개 범위와 재사용 선택을 노출하는 UI가 관찰됐다.
- 승인된 가입 후 무료 100크레딧이 확인됐다.
- Public visibility 기본 상태는 켜짐이었다.
- 이를 끄려 하면 Starter 또는 Pro 업그레이드 안내가 나타났다.
- 따라서 비공개 설정은 유료 플랜 경계로 차단됐고, 비공개 유료 확정 상태로 기록한다.
- 공개·재사용 설정은 변경하지 않았고 업로드·생성·결제도 0건이다.

## 2. 메뉴·정보구조

- 공개 UI에서 이미지 업로드 입력이 관찰됐다.
- 음원 업로드 입력이 관찰됐다.
- 6개 화면비 선택이 보였다.
- 480p와 720p 해상도 선택이 보였다.
- 음악 태그 입력이 보였다.
- Director Style 영역이 보였다.
- Privacy settings 영역이 보였다.
- 가입 모달과 빈 생성 UI는 별도 경계로 관찰됐다.

## 3. 제작동선·입력→작업→결과 연결

- 가입/로그인 경계에는 이메일 코드와 Google 계속 경로가 보였다.
- 실제 가입 뒤 생성 UI에서 이미지·음원 입력을 요구하는 흐름이 확인됐다.
- 출력 비율·해상도·음악 태그·스타일의 선택 문맥이 보였다.
- Privacy settings에는 Public visibility와 재사용 허용 항목이 있었다.
- 입력 파일은 업로드하지 않았다.
- 생성 클릭·접수·렌더·결과 확인은 미실행이다.
- 따라서 입력에서 최종 영상까지의 연결은 부분 관찰에 그친다.

## 4. 상태·오류·수정·재사용

- Public visibility의 기본 ON 상태가 직접 관찰됐다.
- 이미지 재사용 허용과 곡 재사용 허용 체크박스는 모두 미선택이었다.
- 공개 스위치를 OFF로 바꾸는 동작은 성공하지 않았다.
- 업그레이드 안내가 표시됐고 설정 변경은 이루어지지 않았다.
- 생성 실패, 큐, 환불, 수정, 재렌더는 미실행이다.
- 재사용 선택이 결과에 미치는 실제 효과도 검증하지 않았다.
- 기본 공개는 커뮤니티 노출 허용 설명으로 관찰됐으며 모든 결과의 실제 노출을 검증한 것은 아니다.

## 5. 디자인 관찰과 Loretune 제안의 분리

### 관찰

- 생성 변수와 Privacy settings가 같은 제작 맥락에 놓인다.
- 공개 및 재사용 권한을 텍스트 선택으로 분리해 노출한다.
- 유료 플랜 제한은 스위치를 바꾸려는 시점에 안내됐다.
- 픽셀·색상·글꼴·대비 수치와 사용성 점수는 측정하지 않았다.

### Loretune 제안

- 공개 기본값은 생성 전 요약과 함께 두고 안전한 기본값 여부를 설명한다.
- 유료 제한은 설정 변경 시점보다 이전에 표시한다.
- 자료 재사용 동의는 결과 공개와 별도 위험으로 요약한다.
- 이는 관찰 기반 제안이며 코드·설정·서버에 대한 감사 결과가 아니다.

## 6. 레이아웃·반응형·접근성

- 빈 생성 UI의 옵션 그룹과 Privacy settings는 관찰됐다.
- 데스크톱/모바일 전환은 측정하지 않았다.
- 모바일에서 6개 비율과 설정 패널이 어떻게 표시되는지 미확인이다.
- 키보드로 공개 스위치나 체크박스를 조작할 수 있는지 미실측이다.
- 포커스, 대비, 레이블, 오류 연결의 접근성도 미확인이다.
- 약관 모달의 키보드 트랩 여부 역시 확인하지 않았다.

## 7. 무료조건·입출력·시도/접수·실차감

- 가입 무료 표시: 100크레딧.
- 잔여 관찰: 100 → 100.
- 업로드: 0건.
- 생성 시도: 0건.
- 생성 접수: 0건.
- 실차감: 0으로 관찰됐다.
- 개별 생성 견적은 확인되지 않았다.
- 공개 안내에는 무료 최대 20초·워터마크·비상업용 정보가 있었으나 결과로 검증하지 않았다.
- 비공개/공유 제어는 Starter 또는 Pro 필요 안내로 막혔다.

## 8. 스크린샷 출처·시각·한계

- 1MV 전용 스크린샷은 보존되지 않았다.
- 이번 작성 중 새 캡처는 실시하지 않았다.
- 따라서 가입·공개 설정 서술은 기존 일반 브라우저 관찰 기록에 한정된다.
- 캡처 날짜와 생성 결과를 제시할 이미지 근거는 없다.
- 스크린샷 부재는 UI 또는 기능 부재를 뜻하지 않는다.
- 실제 비공개 저장과 결과 공유 상태를 이미지로 검증하지 않았다.

## 9. 도구명/EvidenceID/범위 및 채택/피할점

- 도구명: 일반 브라우저 관찰 기록.
- EvidenceID: 1MV 실제 제품분석 REA Evidence 없음.
- REA의 기존 범위는 1MV와 무관하다.
- Loretune 코드 접근은 OS 차단으로 대조하지 못했다.
- 채택할 점: 공개, 이미지 재사용, 곡 재사용을 구분해 드러내는 설정 표면.
- 피할 점: 공개 기본 ON과 비공개 전환의 유료 장벽을 늦게 알리는 구조.
