# Rotor 경쟁사 개별 보고서

## 1. 최종결론·범위
- 관찰 기준일은 2026-10-25이다.
- 결론 상태는 `BLOCKED_EXTRA_PERMISSIONS`다.
- 완성 생성은 0회다.
- 생성 접수는 0회다.
- 업로드는 0회다.
- 최종 서비스 로그인은 미확인이다.
- YouTube 동영상·계정 관리 권한 확대가 나타나 중단했다.
- 해당 권한은 승인 범위 밖이므로 허용하지 않았다.
- 무료 잔여 크레딧은 미확인이다.
- 결과 품질은 미검증·미완료다.

## 2. 메뉴·정보구조
- 공개 설명에서 음악·클립 분석 기능이 언급된다.
- 공개 설명에서 자동 컷 기능이 언급된다.
- 공개 설명에서 텍스트 기능이 언급된다.
- 공개 설명에서 크롭 기능이 언급된다.
- 공개 설명에서 스타일 기능이 언급된다.
- 이는 공개 설명상의 기능 묶음이다.
- 인증 후 내부 메뉴와 프로젝트 구조는 미확인이다.
- 로그인 완료 전 중단했으므로 자산·설정·기존 프로젝트를 열람하지 않았다.
- YouTube 권한 요청은 메뉴 구조가 아니라 권한 경계로 기록한다.

## 3. 제작동선: 입력→작업→결과
- 공개 설명은 음악과 클립 분석을 전제로 한 제작을 암시한다.
- 자동 컷·텍스트·크롭·스타일은 작업 단계의 공개 설명이다.
- 실제 입력 형식·최소 길이·음악 분석 동작은 미확인이다.
- 실제 클립 선택·수정·프리뷰는 미실행이다.
- 렌더·다운로드·게시 결과는 미확인이다.
- 공개 설명과 실제 실행 동선을 구분한다.
- 결과 영상의 품질·워터마크·해상도는 미검증이다.
- 입력→작업→결과의 실사용 검증은 없다.

## 4. 상태·오류·수정·재사용
- 로그인 완료 전 중단했으므로 생성 상태는 미관찰이다.
- 생성 실패·오류·재시도·환불은 미확인이다.
- 편집 수정과 재생성은 미확인이다.
- 클립·스타일·템플릿 재사용 규칙은 미확인이다.
- YouTube 동영상 관리와 계정 관리 권한은 승인하지 않았다.
- 이 권한 확대는 기본 로그인과 구분한다.
- 권한을 우회하거나 다른 계정을 사용하지 않았다.
- 프로젝트·업로드·생성에 변화는 발생하지 않았다.

## 5. 디자인관찰과 제안 분리
- 확인된 구조는 공개 설명의 기능 분류뿐이다.
- 권한 화면의 존재는 확인했으나 내부 제작 UI는 확인하지 못했다.
- 보존 스크린샷이 없으며 새 캡처도 실시하지 않았다.
- 색상·폰트·여백·레이아웃 수치를 기록하지 않는다.
- 제안: 권한 요청 전에 권한별 필요 이유와 대체 경로를 명시한다.
- 제안: 제작·다운로드 가격과 실제 생성 견적을 별도 표기한다.
- 제안: 외부 계정 관리 권한 없이 가능한 기능을 구분한다.
- 제안은 제품 실행 또는 Loretune 코드 대조의 결과가 아니다.

## 6. 레이아웃·반응형·접근성
- 공개 설명의 페이지 구조 외 UI 레이아웃은 미확인이다.
- 모바일·데스크톱 레이아웃은 측정하지 않았다.
- 반응형 전환점·스크롤·패널 동작은 미측정이다.
- 키보드 조작과 포커스 흐름은 미측정이다.
- 권한 화면의 보조기술 레이블은 미측정이다.
- 대비·폰트 크기·터치 대상도 미측정이다.
- 접근성 적합 여부를 판정하지 않는다.
- 제안: 권한 거절 시에도 가능한 다음 경로를 키보드와 텍스트로 안내한다.

## 7. 무료조건·입출력·시도·접수·실차감
- 무료 잔여와 무료 플랜은 미확인이다.
- 공개 다운로드 가격에는 Music Video 3 크레딧이 보였다.
- Lyric Video는 4 크레딧으로 보였다.
- Spotify Canvas는 1 크레딧으로 보였다.
- 이 값들은 공개 다운로드 가격이다.
- 이 값들을 개별 생성 견적으로 해석하지 않는다.
- 입력 파일을 올리지 않았다.
- 생성 시도·접수·완료는 모두 0회다.
- 실제 차감·환불·워터마크·다운로드 가능 여부는 미검증이다.
- 카드·결제·자동갱신 체험도 실행하지 않았다.
- 공개·비공개 기본값은 미확인이다.

## 8. 스크린샷 출처·시각·미보존
- Rotor의 보존 스크린샷은 없다.
- 새 캡처는 실시하지 않았다.
- 캡처 시각·시각 측정값은 제공할 수 없다.
- 색·폰트·좌표·정확한 화면 구조를 추정하지 않는다.
- REA 제품분석 Evidence는 Rotor에 없다.
- 근거는 보존된 체크포인트의 텍스트 기록이다.

## 9. 도구·Evidence·한계·채택·피할점
- 근거는 `../free-access-checkpoint.md`와 `../approved-tests-checkpoint.md`다.
- 최신 집계는 `../evidence-ledger.md`와 `../sources.md`가 작성되면 링크 가능하다.
- 브라우저 재탐색·로그인·권한 승인·REA 분석을 하지 않았다.
- 개인정보·계정 식별값·이메일 원문·OAuth 쿼리를 제외했다.
- 채택할 점: 분석·자동 컷·텍스트·크롭·스타일을 사용 과업으로 설명하는 방식이다.
- 피할 점: 권한 확대가 필요한 흐름을 기본 로그인으로 축소해 표현하지 않는다.
- 피할 점: 다운로드 가격을 생성 비용이나 무료 생성 근거로 사용하지 않는다.
- 최종 한계: 내부 UI·생성·품질·공개성·실차감은 모두 미완료다.
