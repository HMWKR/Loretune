# Freebeat 개별 경쟁사 관찰 보고서

- 관찰 기준일: 2026-10-25
- 분석 유형: 기존 일반 브라우저 관찰 기록의 재정리
- REA 제품분석 Evidence: 이 사이트에는 없음
- 생성 결과: 0건, 품질: 미검증/미완료

## 1. 최종 결론·관찰/미확인 범위

- Freebeat는 음악 입력과 프롬프트/파일 입력을 제시하는 음악 영상 제작 화면으로 관찰됐다.
- 로그인 성공 뒤 별도 가입·추가 권한·추가 인증 UI는 관찰하지 않았다.
- 업로드와 생성은 모두 실행하지 않았다.
- 무료 잔여 수치는 화면에서 확인되지 않았다.
- 실제 견적과 결과 공개 기본값도 확인되지 않았다.
- 따라서 무료 품질, 출력물, 워터마크 제거 권한을 확정하지 않는다.

## 2. 메뉴·정보구조

- 음악 업로드 시작점이 관찰됐다.
- 프롬프트 또는 파일 입력 경로가 관찰됐다.
- MV 제작 항목이 보였다.
- 댄스 제작 항목이 보였다.
- 리릭 제작 항목이 보였다.
- 실시간 MV 항목이 보였다.
- Photo Karaoke와 온비트 효과 항목도 보였다.
- 이는 기능 표면의 관찰이며 각 기능의 내부 단계를 실행한 기록은 아니다.

## 3. 제작동선·입력→작업→결과 연결

- 음악 업로드 또는 프롬프트/파일이 시작 입력으로 제시됐다.
- 16:9와 720p 선택 항목이 제작 폼에 보였다.
- 자막 제어와 워터마크 제거 토글이 보였다.
- Fast와 Freebeat 2.0 표기도 선택 문맥에서 관찰됐다.
- 실제 입력 파일을 넣지 않았으므로 활성화 조건은 미확인이다.
- 생성 버튼 클릭, 작업 접수, 렌더 대기는 미실행이다.
- 결과·다운로드·게시 연결은 미확인이다.

## 4. 상태·오류·수정·재사용

- 빈 제작 폼 상태만 관찰했다.
- 입력 형식 오류, 길이 제한, 업로드 진행 상태는 미확인이다.
- 생성 대기·실패·재시도 상태도 미관찰이다.
- 생성 후 편집·자막 수정·타임라인 수정은 미실행이다.
- 자산·프로젝트 재사용 흐름은 확인하지 않았다.
- 워터마크 제거 토글이 실제 무료 권한인지 검증하지 않았다.
- Publish류 동작을 결과 공개 기본값의 근거로 사용하지 않는다.

## 5. 디자인 관찰과 Loretune 제안의 분리

### 관찰

- 한 제작 화면에 모델·속도·비율·자막·워터마크 관련 선택이 함께 있다.
- 음악 MV 외 인접 사용 사례를 탐색 단위로 병렬 제시한다.
- 항목의 위계와 실제 필수조건은 생성 전에는 완전히 확인되지 않았다.
- 측정한 px, hex, 폰트, 접근성 점수는 없다.

### Loretune 제안

- 모델 선택과 무료 권한 여부를 같은 위치에서 명확히 구분한다.
- 워터마크 제거처럼 플랜 의존 가능성이 있는 토글에는 즉시 조건을 붙인다.
- 입력 단계에서 결과 형식과 개인정보/공개 범위를 명시한다.
- 이는 관찰 기반 제품 제안이며 구현 감사나 코드 비교가 아니다.

## 6. 레이아웃·반응형·접근성

- 데스크톱 화면의 제작 폼과 선택 제어가 관찰됐다.
- 모바일 레이아웃은 보지 않았다.
- 브레이크포인트와 작은 화면의 메뉴 접힘은 미확인이다.
- 키보드 조작 순서와 포커스 상태는 미실측이다.
- 스크린리더 레이블, 오류 안내, 대비는 미측정이다.
- 자막 토글의 접근성 의미 전달도 확인하지 않았다.

## 7. 무료조건·입출력·시도/접수·실차감

- 공개 UI에는 무료 플랜·카드 불필요 안내가 있었다.
- 실제 무료 잔여 수치는 표시되지 않았다.
- 업로드: 0건.
- 생성 시도: 0건.
- 생성 접수: 0건.
- 실차감: 없음.
- 입력 전 실제 견적은 확인되지 않았다.
- 공개 기본값과 워터마크의 실제 출력 상태도 미검증이다.

## 8. 스크린샷 출처·시각·한계

- Freebeat 전용 스크린샷은 보존되지 않았다.
- 이번 문서 작성 중 새 캡처는 실시하지 않았다.
- 따라서 화면 구성 서술은 기존 일반 브라우저 관찰 기록에 한정된다.
- 캡처 날짜나 파일 수정 시각을 제시할 근거가 없다.
- 이 문서에 생성 결과 이미지나 UI 캡처가 포함되지 않는다.
- 스크린샷 부재는 기능 부재의 증거가 아니다.

## 9. 도구명/EvidenceID/범위 및 채택/피할점

- 도구명: 일반 브라우저 관찰 기록.
- EvidenceID: Freebeat 실제 제품분석 REA Evidence 없음.
- REA의 기존 범위는 이 서비스를 다루지 않았다.
- Loretune 코드 접근은 OS 차단으로 대조하지 못했다.
- 채택할 점: 음악 MV와 인접 제작 유형을 빠르게 비교시키는 진입 구조.
- 피할 점: 토글의 유료/무료 효과와 생성 전 비용을 불명확하게 남기는 경험.
- 근거 색인은 [sources.md](../sources.md)와 [evidence-ledger.md](../evidence-ledger.md)를 참조한다.
