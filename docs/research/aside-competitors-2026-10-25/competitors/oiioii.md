# OiiOii 경쟁사 개별 보고서

## 1. 최종결론·범위
- 관찰 기준일은 2026-10-25이다.
- 결론 상태는 `BLOCKED_AUTH_BOUNDARY_AND_UNCONFIRMED`다.
- 완성 생성은 0회다.
- 생성 접수는 0회다.
- 업로드는 0회다.
- 마지막 표시 크레딧은 60 FREE였다.
- 전후 실측은 없었다.
- 로그인 복귀 중 신규 가입 가능성을 시사하는 표식이 관찰됐다.
- 계정 생성 여부는 확정하지 못했다.
- 추가 가입·계정 변경 없이 중단했다.
- 결과 품질은 미검증·미완료다.

## 2. 메뉴·정보구조
- New Project 진입 UI가 보였다.
- Oii Studio 진입 UI가 보였다.
- Oii TV 진입 UI가 보였다.
- Assets와 Skills 진입 UI가 보였다.
- Free Creation 진입 UI가 보였다.
- Story Video·Storyboard 진입 UI가 보였다.
- Character·Scene·Item Design 진입 UI가 보였다.
- 이는 홈 또는 진입 수준의 구조 관찰이다.
- 에디터 내부·기존 자산·프로젝트 목록은 열람하지 않았다.
- 메뉴의 실제 기능 동작과 계층은 미확인이다.

## 3. 제작동선: 입력→작업→결과
- 공개 진입 UI는 프로젝트와 제작 유형의 분기를 제시한다.
- Story Video와 Storyboard는 제작 방식의 명칭으로만 확인됐다.
- Character·Scene·Item Design은 설계형 시작점으로 보인다.
- 이 관찰은 실제 입력·생성 흐름의 증거가 아니다.
- 입력 필드·지원 포맷·최소 길이는 미확인이다.
- 음악·이미지·텍스트 입력의 실제 요구 여부는 미확인이다.
- 분석·스토리보드·편집·렌더의 실행은 미검증이다.
- 결과 다운로드·게시·재사용은 미확인이다.
- 공개 모델표의 2–72 크레딧/초 범위는 있었다.
- 이 범위는 실제 견적이나 최소 길이를 확정하지 않는다.

## 4. 상태·오류·수정·재사용
- 생성 요청이 없으므로 진행·완료·실패 상태는 미관찰이다.
- 오류 메시지·재시도·환불은 미확인이다.
- 프로젝트 수정·재생성·버전 비교는 미확인이다.
- Assets와 Skills의 실제 재사용 규칙은 미확인이다.
- 에디터와 기존 자산은 의도적으로 열람하지 않았다.
- 로그인 뒤 관찰된 표식은 신규 가입 가능성일 뿐 확정이 아니다.
- 추가 작업·삭제·계정 변경을 하지 않았다.
- 따라서 계정 또는 콘텐츠에 부수효과를 추가하지 않았다.

## 5. 디자인관찰과 제안 분리
- 확인된 UI 구조는 제작 시작점의 다수 카드 또는 진입 분류다.
- 프로젝트·스튜디오·자산·기술 기능을 구분해 진입시키는 방식이 보였다.
- 이 구조 외의 시각 스타일은 기록하지 않는다.
- 보존 스크린샷이 없고 새 캡처도 없었다.
- 색상·폰트·그리드·여백·치수는 측정하지 않았다.
- 제안: 신규 가입 가능성이나 보너스 부여를 명확한 확인 단계로 분리한다.
- 제안: Free 표시 옆에 실제 적용 조건·예상 차감·공개 범위를 제시한다.
- 제안은 Loretune 구현 대조가 아닌 관찰 기반 개선 가설이다.
- Loretune 코드 대조는 OS 접근 차단으로 미실시다.

## 6. 레이아웃·반응형·접근성
- 홈 수준의 진입 구조만 제한적으로 확인했다.
- 화면 폭·높이·그리드 열 수는 미측정이다.
- 모바일 전환·가로 스크롤·패널 접힘은 미측정이다.
- 키보드 이동과 포커스 표시는 미측정이다.
- 보조기술 레이블과 라이브 상태 알림은 미측정이다.
- 대비·글자 크기·터치 대상은 미측정이다.
- 접근성 적합 여부를 판정하지 않는다.
- 제안: 크레딧과 계정 상태의 변화는 색 외 텍스트로도 알린다.

## 7. 무료조건·입출력·시도·접수·실차감
- 마지막으로 60 FREE 표시는 관찰됐다.
- 60 FREE의 구성·만료·무료 보너스 여부는 미확인이다.
- 자동 가입 가능성이 있어 이후 접근을 중단했다.
- 무료 보너스·체크인은 캠페인 조건일 수 있어 확정하지 않는다.
- 실제 생성 견적은 미확인이다.
- 공개 모델표의 단가 범위를 계정 견적으로 쓰지 않는다.
- 공개·비공개 기본값은 미확인이다.
- 입력 파일을 올리지 않았다.
- 생성 시도·접수·완료는 모두 0회다.
- 전후 크레딧 실측과 실차감은 미검증이다.
- 워터마크·결과물 품질·다운로드 조건도 미검증이다.

## 8. 스크린샷 출처·시각·미보존
- OiiOii의 보존 스크린샷은 없다.
- 새 캡처는 실시하지 않았다.
- 캡처 출처·시간을 제공할 자료가 없다.
- 시각 측정·색·폰트·좌표를 발명하지 않는다.
- REA 제품분석 Evidence는 OiiOii에 없다.
- 일반 브라우저 체크포인트의 서술만 근거로 사용한다.

## 9. 도구·Evidence·한계·채택·피할점
- 근거는 `../free-access-checkpoint.md`와 `../approved-tests-checkpoint.md`다.
- 최신 집계는 `../evidence-ledger.md`와 `../sources.md`가 작성되면 연결 가능하다.
- 브라우저 재탐색·로그인·계정 변경·REA를 실행하지 않았다.
- 개인정보·계정 식별값·이메일 원문·OAuth 쿼리를 제외했다.
- 채택할 점: 제작 목적별 진입점을 명확히 나누는 정보구조다.
- 채택할 점: Assets와 Skills를 별도 진입으로 두는 분류다.
- 피할 점: FREE 표기를 자동 가입·무료 생성·실차감 0으로 확대 해석하지 않는다.
- 피할 점: 진입 화면만으로 편집·출력 품질을 평가하지 않는다.
- 최종 한계: 결과물·비용·공개성·접근성은 모두 미완료다.
