# MusicMV 개별 경쟁사 보고서
## 조사 기준
- 작성일: 2026-10-25.
- 범위: 기존 공개 UI 관찰과 최신 build-context, 승인 테스트 체크포인트.
- 이번 작성 단계에서 사이트 재탐색, 생성, 추가 업로드는 하지 않았다.
- 공개 설명, 화면에서 확인한 입력값, 실제 실행 결과를 구분한다.
- 완성 생성·렌더·다운로드는 0건이다.
## 최종 결론
- MusicMV는 노래와 인물 사진을 바탕으로 비트 동기화 뮤직비디오를 제시한다.
- 공개 화면은 업로드 후 AI director가 스토리보드를 작성하고 비트에 맞게 컷을 구성한다고 설명한다.
- 승인 테스트에서 음원과 이미지 업로드는 완료됐지만 생성은 하지 않았다.
- 이유는 결과의 공개/비공개 기본값을 확인하지 못했기 때문이다.
- 따라서 실제 품질, 스토리보드 수정, 렌더 속도, 다운로드 가능 여부는 미검증이다.
- 입력 화면의 견적과 계정 잔여는 확인됐지만 실차감은 확인되지 않았다.
## IA와 메뉴
- 공개 홈 상단에는 Showcase, How it works, Styles, Pricing, FAQ가 보인다.
- 우측에는 언어 아이콘, Sign in, Start free가 배치됐다.
- /create의 공개 제작 UI는 노래, 사진, 설명·스타일, 화면비, 해상도 선택을 제시한다.
- Auto와 Review & Edit 선택지가 보인다.
- 공개 설명은 스토리보드 검토·재생성과 렌더·MP4 다운로드를 후속 단계로 제시한다.
- 이 후속 단계는 실제 실행으로 검증되지 않았다.
## 제작 동선: 입력 → 작업 → 결과
- 공개 UI는 노래 입력을 시작점으로 둔다.
- 표시된 수용 형식은 MP3, WAV, M4A다.
- 공개 화면의 표시 범위는 5초부터 6분이다.
- 메인 사진과 추가 인물 입력이 있다.
- 설명과 스타일을 선택하거나 입력할 수 있다.
- 화면비는 9:16, 16:9, 1:1, 4:3, 3:4가 관찰됐다.
- 해상도 옵션은 768p와 1080p다.
- 작업 방식은 Auto 또는 Review & Edit로 제시된다.
- 승인 테스트에서 자체 WAV와 기하학 PNG를 업로드했다.
- 업로드는 2건이며 서로 다른 원본 입력은 음원과 이미지 2개다.
- 생성 버튼은 활성 상태였으나 클릭하지 않았다.
- 생성 접수, 렌더, 결과 파일은 0건이다.
## 상태·오류·수정·재사용
- 업로드 전에는 생성 버튼이 비활성인 상태가 관찰됐다.
- 입력 후 활성 상태와 표시 견적은 확인됐다.
- 공개 설명은 스토리보드 검토와 재생성을 언급한다.
- 실제 스토리보드 화면, 수정 결과, 재생성 비용은 확인하지 못했다.
- 실행을 하지 않았으므로 진행 상태, 오류 문구, 재시도, 환불은 미검증이다.
- 결과 영상의 재사용·복제·공유 동작도 확인하지 못했다.
- 입력 이미지가 생성물에 어떻게 반영되는지도 미검증이다.

## 디자인 관찰

- 승인 스크린샷은 실제 인물 배경 위에 대형 제목을 중앙에 배치한다.
- 연두색은 로고, 제목 윤곽, CTA에서 반복되는 강조색이다.
- 흰색 텍스트와 어두운 오버레이가 배경 위 정보 계층을 만든다.
- 헤더는 다수의 정보 메뉴와 Sign in·Start free 행동을 함께 둔다.
- 메인 CTA와 예시 영상 CTA가 나란히 배치된다.
- 하단에는 첫 15초 무료, AI 노래 생성, 구독 없음 문구가 함께 표시된다.
- 우하단 언어 전환 팝업은 시야 일부를 차지한다.
- 색상 코드, 폰트, 여백, 대비 수치는 측정하지 않았다.

## 제품에 적용할 제안

- 업로드 단계에서 영상 길이·해상도·예상 크레딧을 즉시 보여 주는 방식을 검토할 수 있다.
- 노래와 인물 이미지의 역할을 입력 필드마다 구분해 안내하는 구조가 유용하다.
- Auto와 검토 기반 작업의 차이는 결과·시간·비용 관점에서 더 명료해야 한다.
- 생성 전 공개 범위와 다운로드 제한을 명시하는 사전 점검 영역을 둬야 한다.
- 스토리보드가 있다면 수정 가능 시점과 재생성 시 차감을 보여 주는 것이 좋다.
- 이 항목들은 경쟁사 UI 관찰에 근거한 제안이며 기능 성공을 주장하지 않는다.

## 레이아웃·반응형·접근성

- 스크린샷 파일 해상도는 2874×1800이다.
- 이 값은 CSS 뷰포트나 반응형 기준이 아니다.
- 캡처에서는 데스크톱 폭의 중앙 히어로와 상단 내비게이션이 보인다.
- 언어 전환 팝업이 콘텐츠 위에 겹쳐 있다.
- 모바일 레이아웃은 관찰하지 않았다.
- 키보드 이동, 포커스, 스크린리더, 대비 수치는 검증하지 않았다.
- 접근성 품질을 이 스크린샷만으로 판정하지 않는다.

## 무료 조건·입출력·실차감·시도·접수

- 계정 표시 크레딧은 20 → 20으로 관찰됐다.
- 입력 후 UI에는 10초·768p·10크레딧 견적이 표시됐다.
- 768p 공개 안내는 초당 1크레딧, 1080p는 초당 2크레딧이다.
- 공개 홈은 첫 15초 무료 문구를 보인다.
- 신규 사용자 20크레딧 및 첫 15초 무료는 공개 정책·UI 기록과 구분한다.
- 무료 영상 워터마크와 크레딧 팩 구매 전 다운로드 제한은 체크포인트의 정책 관찰이다.
- 이 정책 문구는 이 테스트의 실행 결과가 아니다.
- 업로드는 2건이지만 크레딧 차감은 관찰되지 않았다.
- 생성 시도 0회, 생성 접수 0회, 완료 0회다.
- 비공개 기본값이 확인되지 않아 생성하지 않았다.
- 무료 품질, 워터마크 실물, 실차감, 실패 시 처리 모두 미검증이다.

## 승인 입력의 경계

- 음원은 자체 합성 10초 WAV다.
- 사양은 44.1 kHz, 16-bit PCM mono, 120 BPM이다.
- 전자 타악과 단음만으로 구성된 비식별 입력이다.
- 이미지는 1024×1024 RGB PNG다.
- 단색 배경의 원·사각형·삼각형만 포함한다.
- 실제 인물, 사용자 자산, 외부 저작물은 입력에 포함하지 않았다.
- 그러나 화면의 공개/비공개 기본값은 확인되지 않아 결과 생성은 보류했다.
