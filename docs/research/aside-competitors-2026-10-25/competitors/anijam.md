# Anijam 개별 경쟁사 보고서
## 조사 기준
- 작성일: 2026-10-25.
- 범위: 기존 공개 UI 관찰, 최신 build-context, 승인 테스트 체크포인트.
- 이번 작성 중 재탐색, 생성, 입력·업로드는 하지 않았다.
- 공개 홈, 빈 프로젝트 UI, 구독 게이트 관찰을 구분한다.
- 실제 완성 생성과 렌더 검증은 0건이다.
## 최종 결론
- Anijam은 대화형 프롬프트 입력을 중심으로 다양한 영상 제작 도구를 묶어 제시한다.
- 공개 홈은 Text, Script, Image, Audio to Video와 여러 프리셋을 안내한다.
- 인증 뒤 빈 프로젝트에는 Overview, Timeline, Episode, Export 및 다수 도구가 관찰됐다.
- 관찰한 AI Image 기능은 Unlock This Feature 구독 게이트로 차단됐다.
- 그러나 이 한 기능의 구독 제한을 다른 기능 전체의 유료성으로 일반화할 수 없다.
- 표시된 50은 무료분·보너스·구독분의 구분과 만료 조건이 미확인이다.
- 실제 견적, 공개 기본값, 생성 품질, 완료 출력은 모두 미검증이다.
## IA와 메뉴
- 공개 상단에는 Tools, Resources, Pricing, Contact, Careers가 보인다.
- Tutorials, Mobile App, Log in, Start for free도 보인다.
- 공개 프리셋으로 Cinema Lab, Anime Studio, UGC Marketing, Viral Crush가 보인다.
- 빈 프로젝트에서는 Overview, Timeline, Episode, Export가 관찰됐다.
- 도구 목록에는 AI Image, AI Video, Lip Sync, Motion Control이 있다.
- Character, Voice, Style, AI Audio도 확인됐다.
- 이 IA는 다목적 영상 제작 도구의 묶음을 시사한다.
- 각 메뉴의 실제 실행·결과는 확인하지 않았다.
## 제작 동선: 입력 → 작업 → 결과
- 공개 홈은 아이디어를 자연어로 입력하는 큰 입력 영역을 제공한다.
- 미디어 추가 버튼이 있어 참조 입력을 추가할 수 있음을 보여 준다.
- 공개 설명은 텍스트·스크립트·이미지·오디오에서 영상으로의 경로를 제시한다.
- 빈 프로젝트는 개요와 타임라인·에피소드·내보내기 단계를 제공한다.
- Captions와 이미지 출력 형식 UI가 내부 관찰에서 확인됐다.
- 실제 프롬프트 입력은 0건이다.
- 참조 미디어 업로드는 0건이다.
- 생성 시도 0회, 생성 접수 0회다.
- 결과 영상, 타임라인 산출물, 내보내기 파일은 확인하지 않았다.
## 상태·오류·수정·재사용
- AI Image에서 Unlock This Feature 구독 제한을 확인했다.
- 이 화면은 기능 접근이 차단된 상태의 증거다.
- 다른 기능이 같은 제한을 받는지 확인하지 않았다.
- 생성 실행이 없어 대기·성공·실패 상태와 오류 복구는 미검증이다.
- 타임라인 수정, 에피소드 재사용, 캐릭터·스타일 재사용은 미검증이다.
- Lip Sync, Motion Control, Voice 기능도 메뉴 존재만 확인했다.
- 구독 게이트 이후 결제·플랜 변경·재시도는 하지 않았다.

## 디자인 관찰

- 승인 스크린샷은 검은 배경 위 작은 점 패턴을 사용한다.
- 노란색 로고와 원형 전송 버튼이 강조색 역할을 한다.
- 큰 흰 제목 아래에 넓은 대화형 입력 패널을 배치한다.
- 입력 패널에는 미디어 추가와 프롬프트 안내가 함께 보인다.
- 하단 프리셋 카드는 이미지와 제목·설명으로 구성된다.
- 우측 상단 모바일 앱 홍보 패널은 QR 코드와 Copy link 버튼을 포함한다.
- 이 QR 코드는 제품 홍보용이며 사용자 개인 식별 정보로 확인되지 않았다.
- 색상 코드, 타이포그래피, 픽셀 간격, 대비 수치는 측정하지 않았다.

## 제품에 적용할 제안

- 범용 프롬프트 입력과 목적별 프리셋을 함께 제공하는 진입 방식은 참고할 수 있다.
- 다만 프리셋과 실제 생성 경로의 입력·비용·제한을 더 명확히 연결해야 한다.
- 기능별 구독 제한은 생성 버튼을 누른 뒤가 아니라 시작 전에 알려 주는 편이 좋다.
- 타임라인 기반 후속 편집을 제공한다면 생성 전후 작업 상태를 분명히 구분해야 한다.
- 모바일 앱 QR 같은 홍보 패널은 제작 집중을 방해하지 않는 위치·닫기 동작을 고려해야 한다.
- 이 제안은 화면 관찰에 근거하며 실제 기능 성능의 검증이 아니다.

- 키보드 조작, 포커스, 스크린리더 호환성은 확인하지 않았다.
- 대비 수치, 폰트 크기, 터치 타깃은 측정하지 않았다.

- 따라서 “Anijam 전체 기능이 유료”라고 일반화하지 않는다.
