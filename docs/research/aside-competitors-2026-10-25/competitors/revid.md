# Revid 경쟁사 개별 보고서

## 1. 최종결론·범위
- 관찰 기준일은 2026-10-25이다.
- 결론 상태는 `BLOCKED_PRIVACY_UNKNOWN`이다.
- 완성 생성은 0회다.
- 생성 접수는 0회다.
- 업로드는 0회다.
- 가입 보상 70 크레딧이 표시됐다.
- 마지막 관찰에서 활성 유료 플랜은 없었다.
- 결과물 품질은 미검증이다.
- 공개·비공개 기본값은 미확인이다.
- 빈 편집기 진입으로 미디어 없는 초안 1개가 자동 저장됐다.
- 이 초안은 생성 결과와 구분한다.

## 2. 메뉴·정보구조
- 시작점으로 프롬프트·스크립트·음악 경로가 보였다.
- 모델·스타일·캐릭터 선택 영역이 보였다.
- 빈 편집기에는 AI·Script·Text 메뉴가 보였다.
- Media·Transitions·Audio·Captions 메뉴도 보였다.
- Settings 메뉴가 보였다.
- 분할·프레임·트랙을 다루는 타임라인 구조가 보였다.
- Export와 Publish 버튼이 보였다.
- 버튼 존재만으로 게시 기본값을 판단하지 않는다.
- 기존 프로젝트·계정 설정의 민감 필드는 더 읽거나 기록하지 않았다.

## 3. 제작동선: 입력→작업→결과
- 공개 및 내부 UI에서 여러 시작점을 제공하는 구조는 확인됐다.
- 음악 경로는 음악 입력이 필요한 것으로 기록됐다.
- 음악 입력 전 표시된 견적은 약 45 크레딧이었다.
- 이 값은 최종 확정 견적이 아니다.
- 빈 UI의 프롬프트 기본 30초는 18 크레딧으로 보였다.
- 스크립트 시작점은 10 크레딧으로 보였다.
- 이 수치도 실행 결과나 실차감이 아니다.
- 실제 파일 입력·분석·장면 생성은 미실행이다.
- 타임라인 편집·Export·Publish도 미실행이다.
- 입력→작업→결과의 완료 동선은 검증하지 못했다.

## 4. 상태·오류·수정·재사용
- 빈 편집기 진입 시 미디어 없는 초안 1개가 자동 저장됐다.
- 자동 저장은 생성 또는 생성 접수로 계산하지 않는다.
- 기존 초안을 열람하거나 삭제하지 않았다.
- 업로드와 생성 요청은 모두 하지 않았다.
- 진행률·렌더 대기·실패 메시지는 미관찰이다.
- 오류 후 재시도·차감 복구·환불은 미확인이다.
- 타임라인 수정과 재사용은 메뉴 구조만 확인됐고 실행은 미검증이다.
- Publish가 보였더라도 공개 기본값·게시 범위는 확인되지 않았다.

## 5. 디자인관찰과 제안 분리
- 확인된 구조는 시작점 선택과 다중 도구 메뉴다.
- 편집기에는 트랙 기반 타임라인 구조가 있었다.
- Export와 Publish는 결과 단계 진입점으로 보였다.
- 색상·폰트·여백·정확한 크기는 측정하지 않았다.
- 보존 스크린샷이 없으므로 시각적 스타일을 발명하지 않는다.
- 제안: 자동 저장 초안에 ‘생성되지 않음’을 명료하게 표시한다.
- 제안: 음악 입력 전 표시되는 추정 견적을 확정 견적과 구분한다.
- 제안: Publish 전 공개 범위와 비용을 요약한다.
- 제안은 제품 구현 확인이나 코드 대조 결과가 아니다.

## 6. 레이아웃·반응형·접근성
- 메뉴와 타임라인이 한 편집기 화면에 존재하는 구조만 확인됐다.
- 뷰포트 크기와 반응형 동작은 미측정이다.
- 패널 접힘·가로 스크롤은 미측정이다.
- 키보드 조작·포커스·단축키는 미측정이다.
- 스크린리더용 레이블은 미측정이다.
- 대비·색에만 의존하는 상태 표시는 미측정이다.
- 접근성 준수 여부를 판정하지 않는다.
- 제안: 타임라인 상태와 비용 변화는 텍스트 상태로도 제공한다.

## 7. 무료조건·입출력·시도·접수·실차감
- 가입 보상 70 크레딧이 표시됐다.
- 해당 70이 모든 경로에서 사용 가능한 무료분인지는 미확인이다.
- 마지막 확인에서 활성 유료 플랜은 없었다.
- 음악 입력 전 약 45 크레딧 표시는 견적 확정이 아니다.
- 실제 음악 파일을 입력하지 않았다.
- 입력 후 조건·공개성·확정 견적을 확인하지 못했다.
- 생성 시도는 0회다.
- 생성 접수는 0회다.
- 실제 차감은 0→0으로 확인된 것이 아니라 전후 실측이 없다.
- 결과물·다운로드·워터마크는 미검증이다.
- 공개 기본값은 계속 미확인이다.

## 8. 스크린샷 출처·시각·미보존
- Revid의 보존 스크린샷은 없다.
- 새 캡처는 실시하지 않았다.
- 캡처 시각을 별도로 주장하지 않는다.
- UI 색·폰트·치수의 정량 근거는 없다.
- REA 제품분석 Evidence는 Revid에 없다.
- 기록은 일반 브라우저 관찰 체크포인트에 한정된다.

## 9. 도구·Evidence·한계·채택·피할점
- 근거는 `../free-access-checkpoint.md`와 `../approved-tests-checkpoint.md`다.
- 최신 집계는 `../evidence-ledger.md`와 `../sources.md`가 작성되면 링크 가능하다.
- 계정 설정의 민감 정보는 재열람·기록하지 않았다.
- 로그인·추가 업로드·생성·REA 분석을 재실행하지 않았다.
- 개인정보·계정 식별값·이메일 원문·OAuth 쿼리를 제외했다.
- 채택할 점: 다중 시작점과 타임라인 도구의 명시적 분류다.
- 채택할 점: 자동 저장 상태와 생성 상태를 별도 표기하는 설계다.
- 피할 점: 추정 견적을 실제 차감이나 품질 검증으로 쓰지 않는다.
- 최종 한계: 완성 생성·품질 검증·공개성 검증은 모두 미완료다.
