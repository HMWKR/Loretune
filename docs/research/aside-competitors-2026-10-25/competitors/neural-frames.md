# Neural Frames 개별 경쟁사 보고서
## 조사 기준
- 작성일: 2026-10-25.
- 범위: 기존 공개 UI 관찰, 승인 테스트 체크포인트, 최신 build-context.
- 이번 문서 작성 중 브라우저 재탐색과 추가 REA 호출은 하지 않았다.
- 공개 화면, 인증 뒤 읽기 전용 화면, 체크포인트의 관찰을 구분한다.
- 실제 완성 생성·렌더 접수·다운로드는 모두 0건이다.
## 최종 결론
- Neural Frames는 음악에서 출발해 트랙·스토리보드·영상으로 이어지는 제작 단계를 제시한다.
- 공개 홈은 오디오 반응형 AI 뮤직비디오와 창작 제어를 중심 가치로 전면 배치한다.
- /songs 읽기 전용 관찰에서는 단계 UI와 관련 메뉴를 확인했다.
- 다만 실제 본 조사 입력의 업로드, 생성 접수, 렌더 완료, 결과 품질은 검증되지 않았다.
- 마지막 관찰상 50이 표시됐지만 무료분인지, 만료·차감 조건은 확인하지 못했다.
- 해당 제작 방식의 실제 견적과 기본 공개 범위도 미확인이다.
- 따라서 무료 사용 가능, 품질, 렌더 성공을 채택 근거로 삼을 수 없다.
## IA와 메뉴
- 공개 홈에는 로고, Start Now, Visualize Your Music Now CTA가 보인다.
- /songs 관찰에서 Music → Track → Storyboard → Video 순서가 표시됐다.
- 같은 관찰에서 Your Projects 메뉴가 확인됐다.
- Short-Form Studio 메뉴가 확인됐다.
- Autopilot Video 메뉴가 확인됐다.
- Neural Tunes 메뉴가 확인됐다.
- Editor 메뉴가 확인됐다.
- Custom Models 메뉴가 확인됐다.
- 이 메뉴들은 정보 구조의 존재 증거이며 각 기능의 실행 성공 증거가 아니다.
- 개인 기존 작업은 열지 않았다.
## 제작 동선: 입력 → 작업 → 결과
- 공개 설명은 음악 업로드를 제작 시작점으로 제시한다.
- 이어 스타일·캐릭터·비트 싱크 설정을 소개한다.
- /songs UI는 Music, Track, Storyboard, Video의 순차 단계를 제시한다.
- 공개 설명에는 다운로드와 4K 출력 문구가 있다.
- 이 흐름은 제품이 제시하는 동선과 UI 표식의 결합이다.
- 실제 음원 업로드는 0건이다.
- 테스트 프롬프트 입력은 0건이다.
- 생성 작업 접수는 0건이다.
- 렌더 완료는 0건이다.
- 결과 영상·타임라인·출력 파일은 확인하지 않았다.
## 상태·오류·수정·재사용
- 실행된 생성이 없으므로 대기·진행·실패 상태의 실제 표현은 미검증이다.
- 실패 시 환불 또는 크레딧 복구도 미검증이다.
- 스토리보드·장면 수정의 실제 상호작용도 검증하지 않았다.
- 공개 페이지는 장면별 채팅 수정 예시를 소개한다.
- 이 예시는 실제 사용자 작업에서 수정이 성공했다는 증거가 아니다.
- 프로젝트 재사용, 템플릿 복제, 자산 재사용 조건도 확인하지 못했다.
- Custom Models 메뉴가 있어도 모델 학습·재사용이 가능한지 실행으로 확인하지 않았다.

## 디자인 관찰

- 승인 스크린샷은 어두운 전면 비주얼 위에 큰 흰 제목을 중앙 배치한다.
- 보라색 로고와 원형 화살표가 CTA의 강조색으로 반복된다.
- 헤더는 좌측 로고와 우측 Start Now의 단순한 양끝 배치다.
- 히어로 배경은 인물을 가운데 두고 어두운 오버레이로 텍스트를 읽게 한다.
- 신뢰 문구와 별점 요소는 제목 위 작은 보조 정보로 배치된다.
- 이는 캡처 시점의 시각 관찰이다.
- 색상 코드, 폰트명, 대비 수치, CSS 픽셀값은 측정하지 않았다.

## 제품에 적용할 제안

- 음악 입력 직후 단계형 진행 구조를 명확히 보여 주는 방식을 검토할 수 있다.
- 단계마다 다음 행동과 미충족 입력을 함께 표시하는 방향을 제안한다.
- 결과 전에는 예상 비용·공개 범위·출력 조건을 한 화면에서 확인시키는 편이 안전하다.
- 스토리보드는 생성 전 검토와 생성 후 재수정의 상태를 분리해 보여 주는 것이 좋다.
- 장면별 수정 기능을 도입한다면 변경 전후와 재생성 비용을 명시해야 한다.
- 위 제안은 관찰 기반의 제품 제안이며 Neural Frames 구현을 복제하라는 뜻은 아니다.
- Loretune 코드와의 대조는 OS 접근 차단으로 수행하지 못했다.

- 색 대비 수치와 터치 대상 크기도 측정하지 않았다.
