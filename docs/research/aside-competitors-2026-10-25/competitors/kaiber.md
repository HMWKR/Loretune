# Kaiber 경쟁사 개별 보고서

## 1. 최종결론·범위
- 관찰 기준일은 2026-10-25이다.
- 결론 상태는 `BLOCKED_SIGNUP_AND_PAID_TRIAL`이다.
- 완성 생성은 0회다.
- 생성 접수는 0회다.
- 업로드는 0회다.
- 결과물 품질은 미검증이다.
- 결과물의 길이·해상도·워터마크는 미검증이다.
- 실제 크레딧 차감과 실패 환불은 미검증이다.
- 이 문서는 공개 설명과 제한된 가입 경계 관찰만 다룬다.
- 인증 내부의 실제 제작 화면은 확인하지 못했다.
- 원본 보고서와 원본 증거는 변경하지 않았다.

## 2. 메뉴·정보구조
- 공개 설명에서 Canvas가 언급된다.
- 공개 설명에서 Beat Sync가 언급된다.
- 공개 설명에서 Editor가 언급된다.
- 공개 설명에서 자동 가사가 언급된다.
- 공개 설명에서 클리핑이 언급된다.
- 이는 공개 제품 설명의 기능 분류다.
- 내부 메뉴의 실제 배치나 계층은 미확인이다.
- 내부 프로젝트 목록·자산·설정은 열람하지 않았다.
- `/register`에서는 계정 생성 흐름만 확인했다.
- 기존 계정 경로로 Login 버튼이 존재하는 것은 확인했다.
- Login을 실행하거나 기존 로그인 상태를 판별하지 않았다.

## 3. 제작동선: 입력→작업→결과
- 공개 설명상 음악 기반 영상 제작 기능을 알 수 있다.
- Canvas·Beat Sync·Editor가 작업 단계에 관여할 가능성은 있다.
- 그러나 이 순서는 실제 실행으로 검증하지 않았다.
- 공개 설명을 실행 동선으로 동일시하지 않는다.
- 내부 입력 필드·지원 파일 형식은 미확인이다.
- 음악 입력 후 견적이 표시되는지 미확인이다.
- 작업 중 분석·콘티·타임라인의 존재는 미확인이다.
- 렌더 시작·대기·완료 상태는 미확인이다.
- 다운로드·게시 결과의 실제 동작은 미확인이다.
- 따라서 입력→작업→결과의 실행 증거는 없다.

## 4. 상태·오류·수정·재사용
- 실제 생성 요청이 없으므로 생성 상태는 관찰하지 못했다.
- 오류 메시지·재시도·환불 규칙은 미확인이다.
- 수정 도구와 수정 후 재렌더 동작은 미확인이다.
- 재사용 가능한 자산·템플릿의 내부 동작은 미확인이다.
- 가입 화면에는 이메일 구독 선택 항목이 있었고 당시 미선택이었다.
- 이 선택 항목은 제작·공개 설정의 근거가 아니다.
- 가입 제출·약관 동의·캡차 통과는 실행하지 않았다.
- 따라서 계정 생성·자동 저장·프로젝트 생성은 발생하지 않았다.

## 5. 디자인관찰과 제안 분리
- 확인된 UI 구조는 가입 화면의 인증 방법 분기다.
- Google·Apple 계속 버튼과 이메일·비밀번호·확인 입력이 보였다.
- 이미 계정이 있는 이용자를 위한 Login 경로도 보였다.
- 색상·폰트·간격·시각적 위계는 측정하거나 기록하지 않았다.
- 보존 스크린샷이 없으므로 시각적 외관을 추정하지 않는다.
- 제안: 가입 전 무료 여부·최소 견적·공개 기본값을 한 화면에 명시한다.
- 제안: 공개 설명의 기능명과 실제 제작 단계의 연결을 안내한다.
- 제안은 Loretune 코드 대조 결과가 아니다.
- Loretune 코드 대조는 OS 접근 차단으로 미실시다.

## 6. 레이아웃·반응형·접근성
- 가입 화면의 필드와 버튼 구조만 제한적으로 확인했다.
- 데스크톱·모바일 레이아웃은 측정하지 않았다.
- 반응형 전환점은 미측정이다.
- 키보드 순서와 포커스 표시는 미측정이다.
- 스크린리더 이름·역할·상태는 미측정이다.
- 대비·글자 크기·터치 대상은 미측정이다.
- 접근성 적합 여부를 판정하지 않는다.
- 제안: 가입과 제작 화면에서 공개 범위와 비용을 키보드로도 사전 확인 가능하게 한다.

## 7. 무료조건·입출력·시도·접수·실차감
- 공개 가격 관찰의 `$5/5일`은 유료 체험이다.
- 이 체험은 무료 이용으로 분류하지 않는다.
- 이후 Creator 전환 안내가 있었던 것으로 기록돼 있다.
- 공개 무료 플랜은 확정하지 못했다.
- 무료 잔여 크레딧은 미확인이다.
- 실제 최소 생성 견적은 미확인이다.
- 카드·자동갱신 체험·결제는 실행하지 않았다.
- 입력 파일을 올리지 않았다.
- 생성 시도·접수·완료는 모두 0회다.
- 실제 차감은 0으로 검증된 값이 아니라 실행 자체가 없었다.
- 공개·비공개 기본값은 미확인이다.

## 8. 스크린샷 출처·시각·미보존
- Kaiber의 보존 스크린샷은 없다.
- 새 캡처는 실시하지 않았다.
- 따라서 색·폰트·좌표·치수 관찰을 제시하지 않는다.
- 관찰 시각은 기준일 2026-10-25 외 별도 캡처 타임스탬프가 없다.
- REA 제품분석 Evidence는 이 사이트에 없다.
- 일반 브라우저 관찰과 REA Evidence를 혼동하지 않는다.

## 9. 도구·Evidence·한계·채택·피할점
- 근거는 `../free-access-checkpoint.md`와 `../signup-boundaries.md`다.
- 최신 상태·집계는 `../evidence-ledger.md` 및 `../sources.md`가 작성되면 교차 참조 가능하다.
- 이번 문서는 브라우저 재탐색·로그인·REA 호출을 하지 않았다.
- 개인정보·계정 식별값·이메일 원문·OAuth 쿼리를 제외했다.
- 채택할 점: 공개 기능 언어를 Canvas·Beat Sync·Editor처럼 작업 목적별로 나눈다.
- 피할 점: 체험 가격을 무료 조건으로 표현하지 않는다.
- 피할 점: 공개 설명을 실제 제작·출력 검증으로 확대하지 않는다.
- 최종 한계: 제작 결과·품질·비용·공개성은 모두 미완료다.
