# Tunee 개별 경쟁사 관찰 보고서

- 관찰 기준일: 2026-10-25
- 분석 유형: 기존 일반 브라우저 관찰과 보존 이미지에 한정한 문서화
- REA 제품분석 Evidence: 이 사이트에는 없음
- 생성 결과: 0건, 품질: 미검증/미완료

## 1. 최종 결론·관찰/미확인 범위

- Tunee는 음악을 입력으로 받는 MV Studio 진입 구조가 관찰됐다.
- 실제로 자체 합성 WAV 1건을 업로드했고 10초 구간과 음악 스타일을 확인했다.
- 만들기 버튼은 실행하지 않았고, 생성 접수는 0건이다.
- 표시 잔여는 250 Free에서 250 Free로 유지됐다.
- 최종 생성 견적과 결과의 공개 기본값은 확인되지 않았다.
- 따라서 무료 생성 가능, 결과 품질, 워터마크, 완성 파일을 주장할 수 없다.

## 2. 메뉴·정보구조

- 기존 내부 UI에서 에이전트 메뉴가 관찰됐다.
- 동영상 메뉴가 관찰됐다.
- 캐릭터 메뉴가 관찰됐다.
- 프로젝트 메뉴가 관찰됐다.
- 라이브러리 메뉴가 관찰됐다.
- 빈 MV Studio에는 원클릭 MV 진입 항목이 보였다.
- 프리스타일 MV 진입 항목이 보였다.
- 모션 제어와 쇼츠 진입 항목도 보였다.
- 이는 메뉴 존재 관찰이며 각 하위 기능의 실행 검증은 아니다.

## 3. 제작동선·입력→작업→결과 연결

- 관찰된 시작점은 필수 음악 입력이 있는 MV Studio다.
- 자체 합성 WAV를 1건 업로드했다.
- 업로드 후 10초 구간 선택을 수행했다.
- 음악 스타일을 확인했다.
- MiniMax H3 표기는 선택 가능 요소로 관찰됐다.
- 선택 자산 영역도 보였으나 추가 자산을 사용하지 않았다.
- 만들기는 미실행이므로 분석·콘티·프레임·렌더 연결은 미실행이다.
- 결과 화면과 다운로드 경로도 미확인이다.

## 4. 상태·오류·수정·재사용

- 입력 전 만들기 제어는 비활성 상태로 관찰됐다.
- 업로드 후의 생성 전 상태만 확인했다.
- 생성 요청·큐·완료·실패 상태는 관찰하지 않았다.
- 오류 메시지와 재시도 동작도 미확인이다.
- 결과 수정, 타임라인 수정, 버전 복제는 미실행이다.
- 프로젝트 재사용 또는 자산 재사용 정책도 미확인이다.
- 비공개 상태에서의 저장·재진입은 검증하지 않았다.

## 5. 디자인 관찰과 Loretune 제안의 분리

### 관찰

- 메뉴와 작업 영역이 분리된 제작 도구 구조가 확인됐다.
- 여러 MV 시작 모드를 한 화면에서 제시하는 구성이다.
- 입력 충족 전 만들기를 비활성화하는 상태 표현이 보였다.
- 크기, 색상값, 글꼴, 대비 점수는 측정하지 않았다.

### Loretune 제안

- 입력 누락, 견적 미확인, 공개 범위 미확인을 별도 체크로 드러낸다.
- 생성 전 요약에 길이·모델·예상 차감·공개 범위를 함께 둔다.
- 결과 없는 초기 화면에서는 다음 한 단계만 우선 안내한다.
- 이는 경쟁사 관찰 기반 제안이며 코드 대조 결과가 아니다.

## 6. 레이아웃·반응형·접근성

- 데스크톱성 작업 영역과 좌측 탐색 구조는 관찰됐다.
- 실제 모바일 화면은 측정하지 않았다.
- 반응형 전환 규칙은 미확인이다.
- 키보드만으로의 탐색·업로드·만들기 조작은 미실측이다.
- 포커스 표시, 스크린리더 이름, 오류 연결은 미확인이다.
- 명도 대비와 터치 대상 크기도 미측정이다.

## 7. 무료조건·입출력·시도/접수·실차감

- 표시 잔여: 250 Free → 250 Free.
- 업로드: 1건.
- 만들기 시도: 0건.
- 생성 접수: 0건.
- 실차감: 관찰되지 않음.
- 최종 견적은 음악 입력 이후에도 확정 확인하지 못했다.
- 무료 MV의 워터마크 언급은 기존 공식 FAQ 기준이며 이번 결과로 검증하지 않았다.
- 공개/비공개 기본값은 UI에서 확인하지 못했다.
