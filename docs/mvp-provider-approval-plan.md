## 완료 기준

동일 작품의 채팅형/작업대에서 음악과 장면 요청을 입력하고, 승인된 시작 이미지로 실제 AI 영상 2개를 생성한다. 샷별 결과를 검토하고 한 샷만 다시 생성해 기존 승인본이 보존되는지 확인한다. 선택한 두 샷을 음악과 자막이 포함된 10초 MP4로 내보내고 파일의 시간·오디오·해상도를 측정한다. 새로고침/재시작 후 작업·버전·선택·원장·출력은 복구되어야 한다. 응답 유실 시 유료 요청을 자동 재발행하지 않는다.

현재 곡/요청·로컬 초안·수동 미디어 연결·검토·부분 편집·출력은 동작한다. 규칙 기반 초안은 AI 기획이 아니다. 실제 AI 생성과 승인된 외부 연결은 남아 있다. 96FR/143API는 계속 추적하되 조직 SSO/결제/정교한 자동 음악분석/립싱크/무한캔버스/공유배포는 이 최소 MVP 이후다. 장면 자동 기획 LLM도 이 검증에서는 사용하지 않는다.

## 추천: Runway Dev / gen4_turbo

기존 `cost_scenarios.json`의 후보와 일치한다. 공식 모델 목록에 존재하며 이미지→영상 생성과 작업 조회 API가 있다. 영상은 지정 시작 프레임과 사용자가 확인한 프롬프트로 생성하고 음악 합성은 기존 로컬 FFmpeg가 담당한다. 이는 가창 립싱크 검증이 아니다.

- 전송: 새로 만든 비식별 추상 풍경 PNG 2장(1280×720), 장면 프롬프트 2개와 수정 프롬프트 1개. 사용자 기존 사진·가사·음원·세계관 문서·계정정보는 전송하지 않는다.
- 최소 유료 생성: 5초 영상 2개 + 한 샷 재생성 1개 = 3회. 한 번에 하나, 자동 재시도 없음. 작업 조회는 별도이며 5초보다 자주 조회하지 않는다.
- 공식 단가: 5 credits/초, 1 credit=$0.01. 3×5×5=75 credits=$0.75 예상. 추가 1회가 필요한 경우까지 **총4회/100 credits/$1.00 생성 사용량 상한**을 제안한다. 환율·세금·결제 충전액은 이 상한과 별개다. 유실된 생성도 호출 슬롯과 예약액을 유지해 추가 발행을 막는다.
- **신규 API 프로젝트의 최소 충전은 $10**으로 공식 안내된다. $0.75 사용량과 $10 결제는 다르다. 기존 잔액 여부는 확인하지 않았으며 구매/자동충전은 실행하지 않는다. 결제가 필요하면 별도 명시 승인이 필요하다.
- 승인 질문(부모 전달용): “Runway Dev에 비식별 테스트 이미지·프롬프트만 전송하여 5초 생성 최대4회, 생성 사용량 $1 상한으로 검증해도 될까요? API 연결은 직접 안전하게 설정해 주세요. 신규 충전이 필요하면 최소 $10 결제는 별도 결정하며 자동충전은 켜지 않습니다.”

## 안전한 연결 단계 — 승인 후 사용자 직접 수행

1. https://dev.runway.com/ 에 직접 로그인하고 테스트 전용 프로젝트를 선택한다. 기존 서비스 구독이 API 잔액을 의미한다고 가정하지 않는다.
2. API Keys에서 테스트용 키를 직접 생성한다(생성 권한/지속 접근에 대한 사용자 승인 필요). 키는 채팅·스크린샷·저장소에 붙여넣지 않는다.
3. 승인된 비밀 주입 방식으로 서버 프로세스에만 제공한다. 현재 `.env`를 읽거나 수정하지 않았다. 적용 방식은 승인 후 정하며 이 문서가 설정 작업의 승인은 아니다.
4. 테스트 잔액/요금 확인 후 총4회/$1 사용 한도를 승인한다. 자금 충전·결제·자동충전은 별도다.
5. 실제 전송 직전 이미지·프롬프트·길이·단가·요청수를 화면에서 확인한다. 완료 후 키 폐기 여부는 사용자가 결정한다.

## 현재 어댑터와 검증 경계

기존 실행기는 `app.py`의 로컬 FFmpeg 작업뿐이며 Runway 네트워크 어댑터는 기존에 없었다. 새 어댑터/원장/상태 전이 검증은 격리 fake transport로 진행한다. 테스트 통과는 Runway 계정접근·생성 품질·실제 과금/환급 확인이 아니다. 실제 연결 후에만 provider 통합 pass를 기록한다.
