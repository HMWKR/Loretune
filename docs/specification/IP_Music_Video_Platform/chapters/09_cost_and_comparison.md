# 9. 길이와 제작 범위별 비용 비교 및 발표용 수치 기준

문서 기준일 2026년 10월 23일. 외부 가격은 이 날짜에 확인한 판매자의 공개 안내다. 우리 비용은 `cost_model.json`의 입력값으로 계산한 예산 시나리오다. 실제 주문 견적, 시장 평균, 과거 전체 업계의 가격, 실제 제품의 평균 제작비가 아니다.

## 9.1 무엇을 같은 조건으로 비교할 것인가

영상의 길이가 같아도 새 일러스트, 촬영, 정확한 안무, AI 장면 생성, 가사 편집은 서로 다른 작업이다. 3분짜리 정지 그림 MV와 3분짜리 다인 퍼포먼스를 같은 상품으로 취급하지 않는다. 아래 7개 항목이 맞지 않으면 가격 차이를 관찰할 수는 있어도 절감률이나 동등 품질을 주장할 수 없다.

| 비교 항목 | 반드시 기록할 값 |
|---|---|
| 산출물 | 정확한 완성 길이, 화면비, 파일 규격, 소스 해상도, 프레임률, 버전 수 |
| 제작 유형 | 기존 자산 편집 / 혼합 생성 / 전부 생성 / 촬영 / 3D 퍼포먼스 |
| 고객 제공물 | 곡·가사·믹스·그림·파츠·촬영본·브리프의 유무와 준비 시간 |
| 제작자 범위 | 기획·신규 그림·생성·합성·자막·편집·색보정·검수의 포함 여부 |
| 수정 조건 | 후보 수, 검토 회차, 새로운 기획·소재 교체·재생성의 추가 요금 |
| 경제 조건 | 표시가/시작가, 세금, 구매 수수료, 구독 배부, 작업자 인건비 |
| 시간과 품질 | 실행 시간, 달력상 납기, 고객 활동 시간, 납품 승인률, 설정 오류 |

판매자의 공개 납기는 접수·대기·고객 응답·작업을 포함할 수 있다. 우리 모델의 생성 대기시간만 대응시켜 ‘14일에서 5분’이라고 발표하지 않는다. 원본 그림 비용이 이미 지출됐다고 하더라도 처음 고객의 총예산에서는 사라지지 않는다. 재사용 프로젝트 비교와 첫 제작 비교를 별도 표로 관리한다.

## 9.5 180초 혼합 예제의 재현 가능한 계산

완성 길이 D=180초, 새 생성 비율 g=0.5, 계획 샷 길이 L=5초, 후보 k=2로 둔다. 이 경우 새 생성 채택분 90초를 18개 샷으로 구성한다. 각 샷이 5초 전부 사용된다는 가정이다.

1. 생성 샷 수 = ceil(D×g/L) = 18개.
2. 과금 영상 길이 = 18×5×2 = 180초; 영상비 = 180×$0.05 = $9.00.
3. 영상용 키프레임 이미지 후보 생성 = 18×2 = 36장; 이미지비 = 36×$0.08 = $2.88.
4. 분석·렌더·전송 충당 = $0.20 + 3×$0.60 = $2.00.
5. 외부 변동비 예산 = $13.88×1,400 = 19,432원.
6. 사용량 청구 가설 = 19,432×1.30 = 25,261.60원.
7. 편당 현금 = 249,000/4 + 25,261.60 = 87,511.60원.
8. 고객 노동 가치 = 75분/60×30,000 = 37,500원; 편당 경제비용 = 125,011.60원.

최종 180초, 새 생성 채택 90초, 공급자 청구 180초는 서로 다른 값이다. 예를 들어 5초 생성물 중 2초만 채택하면 샷 수와 비용이 더 늘어난다. 위 수식은 과금된 실패·추가 이미지 수정·소스 교체의 분포를 관측한 결과가 아니다. 실측 시에는 공급자 원장의 청구 단위가 우선하며 계획식으로 실제 원장을 덮어쓰지 않는다.

```bash
python cost_model.py --seconds 180 --mode hybrid --model gen4_turbo --candidates 2 --monthly-outputs 4
python cost_model.py --seconds 60 --mode asset --monthly-outputs 1 --first-project
python cost_model.py --seconds 180 --mode hybrid --support-minutes 120
python -m unittest -v test_cost_model.py
```

계산기는 오프라인 예산 도구다. 모델 호출, 결제, 영상 생성, 계정 접속을 하지 않는다. 입력과 출력·코드 버전·출처를 보존해야 나중에 같은 숫자를 재현할 수 있다. COST ID는 길이·제작 모드 묶음이고, calculation_id는 후보 수·모델·월 편수·지원 시간을 포함한 전체 입력의 해시로 개별 계산을 식별한다.

## 9.6 플랫폼 사업자의 단위경제성과 숨은 지원 노동

플랫폼 지원 시간은 고객 자신의 편집 시간과 분리한다. 다음 표는 앞의 180초 혼합·월 4편 시나리오에서 지원 시간만 바꾼다. 지원 인건비 30,000원/시간, 팀 고정 인프라 6,000원/월, 결제비 매출의 3.5%, 환불 충당 매출의 2%를 가정한다. 모두 실제 계약·운영으로 측정하지 않은 입력값이다.

| 편당 플랫폼 지원 시간 | 지원 노동 원가 | 편당 공헌이익 | 공헌이익률 |
| --- | --- | --- | --- |
| 20분 | 10,000원 | 51,766원 | 59.15% |
| 60분 | 30,000원 | 31,766원 | 36.30% |
| 120분 | 60,000원 | 1,766원 | 2.02% |
| 180분 | 90,000원 | -28,234원 | -32.26% |

기본 지원 20분에서 월 4편의 공헌이익은 약 207,066원이다. 월 고정비를 임의로 1,200만원이라 두면 산술 손익분기점은 약 58팀이다. 지원 60분/편이면 약 127,066원/팀·월로 낮아져 약 95팀이 필요하다. 고객 수·획득 시점의 예측이 아니며 개발·영업·경영 고정비는 별도로 포함해야 한다. 가격·변동비·사용 빈도를 바꾸면 전부 재계산한다.

고객당 지원이 120분/편이면 기본 편당 공헌이익은 약 1,766원까지 낮아진다. 창업자가 직접 장면을 고치고 납품하는 시간을 누락하면 가장 중요한 위험이 숨겨진다. **‘AI 비용이 낮다’는 사실만으로 SaaS 이익률을 예측하지 않는다.** 대행이 반복되면 지원 범위를 제한하거나 해당 작업을 제작 서비스로 별도 가격화한다.

## 9.7 저가 경쟁까지 고려한 구매 논리

60~70초 3,000엔 편집 대안과 비교하면 월 구독 249,000원은 낮은 빈도의 개인 창작자에게 불리할 수 있다. 저렴한 외주와 기존 편집 도구만으로 만족하는 고객에게 높은 관리비를 추가할 이유는 약하다. 우리 초기 고객은 여러 작품·멤버·승인자를 다루며 반복 설명과 수정 전달의 비용이 실제로 큰 팀이어야 한다. 이는 조사할 고객 선택 기준이며 이미 입증된 수요가 아니다. [DP-03]

고객별 구매 경제성은 `외주 현금 + 고객 조율 시간가치 + 재작업 비용`과 `우리 이용료 + 고객 조작·검토 시간가치 + 추가 외주 비용`을 같은 기간·품질에서 비교한다. 현재 외주 담당자가 IP를 이미 잘 알고 있다면 기억 이점이 작아질 수 있다. 최종 승인 품질이 낮으면 가격 차이만으로 승리로 판정하지 않는다. 개별 고객에게서 절약한 총비용을 측정하기 전 전체 시장에 적용되는 절감률을 발표하지 않는다.

## 9.8 ‘보통 이 정도’라고 말하기 위한 실측 계획

기존 EXP-001~016의 정의는 유지하고 이 절의 가격·작업 비교 기록을 추가로 수집한다. 가격 실측을 위한 새 계획은 EXP-C01~C04이며 아직 실행하지 않았다. 샘플이 부족한 모드를 합쳐 전체 평균으로 표시하지 않는다.

| 실험 | 자료와 비교 | 다음 단계의 최소 판단 |
|---|---|---|
| EXP-C01 범위 맞춘 외주 견적 | 동일한 60초·180초 브리프, 고객 제공 자산, 1차·최종 검토, 저가/중가/스튜디오별 견적 | 최소 3개 유효 견적의 범위·세금·추가비를 확인. 의뢰·결제는 별도 실제 구매 결정 |
| EXP-C02 원가 계측 | 우선 30~60초 지원 모드, 최소 8팀·24개 요청을 탐색 표본으로 기록 | 성공·실패·지원 포함 원장 대사, 고객별 분포 공개. 통계 대표성이나 성공률 보장으로 해석 금지 |
| EXP-C03 작업 수와 시간 | 동일 팀의 실제 수작업/단순 브랜드 문서/구조화 기억 경로를 대조 | 3번째 요청의 총 활동 시간·재설명·검토 회차 비교, 역할별 부담 증가까지 반영 |
| EXP-C04 지불과 빈도 | 월·프로젝트 가격 제안, 실제 결제·제작 기회·휴면·재구매 기록 | 가격 할인·무료 대행과 정상 이용 분리. 매월 4편 가정이 유효한지 확인 |

표본 크기는 파일럿 실행 계획일 뿐 효과를 통계적으로 입증할 충분 표본이라는 뜻이 아니다. 품질·비용의 분산과 팀 내 상관을 관찰한 뒤 본검증 표본을 산정한다. 180초 지원은 길이·장면 수·운영 복구에 관한 별도 게이트를 통과한 뒤 실험한다.

원가 로그에는 team_id, project_id, mode, output_seconds, generated_accepted_seconds, provider_job_id, model_version, actual_billed_units, net_charge_currency, refund, fx_basis, accepted/rejected 상태, 운영자 시간, 고객 활동 시간, 미완성 종료 이유를 남긴다. 승인되지 못한 프로젝트도 분자 비용에 포함한다. `승인된 1편당 비용 = 코호트의 모든 시도 총비용 / 승인 납품 편수`로 보고하고 승인 납품 0이면 값은 미정으로 표시한다. 납품되지 않은 요청을 제외한 성공 사례 평균을 대표 수치로 제시하지 않는다.

배포 가능한 결과에는 표본 n, 팀 수, 기간, 모드, 길이, 중앙값, p90, 실패·중단 비율, 지원 분, 공급자 버전, 누락 데이터 비율을 함께 표기한다. 사용량 원장과 청구의 대사가 끝날 때까지 해당 코호트의 확정 원가 발표를 보류하고, 미대사 기간·건수·추정 비용 범위를 공개한다. 대사 완료 후 실패를 포함한 전체 코호트에 반영한다. 정상 기간의 잠정 분석에도 누락 범위를 표시한다. 평균 하나로 크게 다른 제작 유형을 합치지 않는다.

## 9.9 PPT에 바로 쓸 수 있는 숫자 문장과 사용 조건

**지금 사용 가능한 문장 A — 공개 사례.** “2026-10-23 공개 상품에는 60초 AI MV 제작 대행 449,000원(구매 수수료 별도, 수정 2회)이 있다. 더 단순한 60~70초 편집 상품은 3,000엔부터 제시되므로 제작 범위를 맞춰 비교해야 한다.” [DP-01][DP-03]

**지금 사용 가능한 문장 B — 우리 설계 예산.** “월 4편, 고객 제공 자산, 180초 중 90초 새 생성, 샷당 후보 2개를 가정하면 편당 이용료는 약 87,512원이다. 구독 249,000원/월과 사용량 가산을 포함한 검증 전 모델이며, 세금·고객 노동·새 일러스트·촬영은 별도다.” 숫자 옆에 가정을 같은 슬라이드 안에 표시한다.

**지금 사용 가능한 문장 C — 핵심 가치 가설.** “반복 제작에서 공식 설정·승인 자산·거절 이유를 다시 연결하고, 준비된 IP의 새 초안을 4개 주요 결정으로 실행하도록 설계했다.” 클릭 수, 최종 납품, 실측 성과로 표현하지 않는다.

**실측 후에만 허용할 문장.** “동일 조건의 n팀·m건에서 세 번째 요청의 활동 시간이 대조군 대비 X% 줄었고, 승인 품질을 유지했다.” 실험 등록·원본 로그·품질 기준·분모·신뢰구간과 기준일이 연결되어야 한다.

**현재 근거로 사용할 수 없는 문장.** “기존에는 무조건 300만원, 우리는 3만원”, “12단계가 4클릭으로 줄어 67% 절감”, “3분 MV를 평균 8만원에 무수정 완성”, “온톨로지가 다른 경쟁사에는 없다”, “동일 품질 90% 저렴”, “AI 비용이 2만원이므로 90% 이익률”.

발표 자료도 독립 원본이 아니다. 각 숫자를 Claim ID와 입력 모델 버전·출처 ID에 연결하고, 가격이나 범위가 바뀌면 해당 슬라이드를 재검토 대상으로 만든다. 제8장의 문서 CLI가 이 관계를 관리한다.
