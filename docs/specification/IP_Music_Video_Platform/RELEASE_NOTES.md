# v2.0 변경 기록

- 기존 사업·제품·기술·UX 문서를 통합 유지하고, 제작 과정·길이별 비용·PPT 문장·프로젝트 CLI 두 권을 추가했다.
- 12개 업무, 네 가지 주요 결정, UI 조작, 생성 후보, 검토 라운드를 분리했다.
- 30/60/180초, 자산/혼합/생성 중심, 월 빈도·후보·지원 노동의 단일 비용 모델을 적용했다.
- 1차 출처의 공개 가격과 저가 대안·제외 사례를 함께 기록했다. 시장 평균·동등 품질·실측 평균으로 주장하지 않는다.
- 신규 키프레임 이미지 생성 단위와 업로드 참조 비용을 구분했다.
- 각 API operation에 미구현 상태를 기계 판독 필드로 명시했다.
- Source·Claim·Assumption·Requirement·Screen·API·Test·Metric·Document 관계, 승인 head, hash, 시간, archive, context receipt를 구현했다.
- 실제 로컬 시험 26개, 정적 검사 93개, 전달 registry 통합과 변경 전파를 확인했다.
- v1은 키트의 archive에 보존하며 현행 비용 근거로 기본 선택하지 않는다.

문서 편집 기준선 확정은 사용자의 사업 채택이나 제품 성능 검증을 뜻하지 않는다. 제품 실행·모델 출력·실제 비용·유료 수요는 아직 not_run이다.
